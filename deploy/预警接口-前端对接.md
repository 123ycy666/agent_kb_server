# 每日预警接口文档

## 1. 概述

| 项 | 值 |
|---|---|
| 接口地址 | `http://47.121.183.81:8200/api/alerts/daily` |
| 请求方法 | `POST` |
| Content-Type | `application/json; charset=utf-8` |
| 功能 | 按登录账号返回该账号当日的预警列表，每条预警一句话 |
| 鉴权 | 由调用方完成；本接口以 `account` 判定角色与数据范围 |
| 响应时间 | 实测 100~160 毫秒 |

## 2. 请求参数

```json
{
  "account": "sngdssz",
  "today": "2026-10-15",
  "when": "2026-10-15 08:00",
  "limit": 10
}
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `account` | string | 是 | 登录账号（员工表 `login_name`）。也兼容字段名 `uid` |
| `today` | string | 否 | 业务日期 `YYYY-MM-DD`。年度、滞留天数、进度均以此计算；缺省取服务器当天 |
| `when` | string | 否 | 触发时刻，仅回显 |
| `limit` | int | 否 | 明细条数，默认 10，上限 50。仅影响 `items`，不影响 `title` 与 `total` |

`scope`、`role` 不作为入参：角色与数据范围由 `account` 解析，传入不生效。

## 4. 响应字段

### 4.1 顶层字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `status` | string | `abnormal` 有预警 / `ok` 无预警 / `unknown` 账号无法解析 |
| `account` | string | 账号原值回显 |
| `name` | string | 姓名，可能为空串 |
| `role_code` | string | 角色码（见 6.2） |
| `role` | string | 角色中文名 |
| `scope` | string | 数据范围名称 |
| `scope_type` | string | `station` 单个供电所 / `county` 县公司 / `city` 全市 |
| `station_ids` | int[] | 本次统计覆盖的供电所 id 列表；`unknown` 时为 `null` |
| `today` | string | 业务日期回显 |
| `triggered_at` | string | 触发时刻回显 |
| `checked_at` | string | 服务端实际检查时刻 |
| `elapsed_ms` | int | 本次耗时（毫秒） |
| `suppressed` | string[] | 因单账号条数上限被截断的预警类型码 |
| `error` | string | 仅 `status=unknown` 时出现，见 5 |

### 4.2 `alerts[]` 元素字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `alert_type` | string | 预警类型码（见 6.1） |
| `alert_label` | string | 预警类型中文名 |
| `level` | string | `high` / `mid` / `low`；数组已按此排序 |
| `title` | string | 预警正文，一句话，≤44 字，只陈述事实 |
| `total` | int | 命中总数 |
| `amount` | number | 涉及金额，单位元 |
| `data` | object | 该类型的补充字段 |
| `items` | object[] | 明细列表，仅部分类型返回；`returned` 为其条数 |

### 4.3 `data` 字段（按 `alert_type`）

| `alert_type` | `data` 字段 |
|---|---|
| `budget_underspend` | `alloc` 分配额 / `left` 结余 / `zero_stations` 未启动所数 / `stations` 命中所数 / `worst[]` 最严重所 / `year_end` 年底预计已批 |
| `zero_execution` | `alloc` 涉及分配额 / `stations` 所数 |
| `approval_backlog` | `cnt` 件数 / `amount` 金额 / `over_90` 超 90 天件数 |
| `node_stay_overdue` | `node` 节点名 / `cnt` 件数 / `over_90` 超 90 天件数 / `max_days` 最长滞留 / `amount` 金额 |
| `node_backlog` | `by_node` 各环节件数 |
| `approved_not_started` | `cnt` 件数 / `amount` 金额 / `max_days` 最久天数 |
| `extreme_amount` | `limit` 阈值 / `cnt` 件数 |
| `data_quality_amount` | `cnt` 件数 / `amount` 金额 |
| `data_quality_status` | `cnt` 件数 / `amount` 金额 |
| `data_quality_missing` | `cnt` 件数 / `missing` 缺失条数 |
| `metric_deteriorated` | `period` 期次 / `items[]` 各指标本期、基期、变化率 |

### 4.4 `items[]` 元素字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `work_order_id` | int | 工单 id |
| `name` | string | 工单名称 |
| `station` | string | 供电所名称 |
| `amount` | number | 金额，单位元 |
| `node` | string | 当前审批节点 |
| `days` | int | 滞留天数 |
| `level` | string | 分档：正常 / 偏慢 / 积压 |
| `is_new_today` | bool | 是否今日进入该节点 |

## 5. 状态与错误码

| HTTP | `status` | 场景 |
|---|---|---|
| 200 | `abnormal` | 有预警 |
| 200 | `ok` | 无预警，`alerts` 为空数组 |
| 200 | `unknown` | 账号无法解析，`alerts` 为空数组，`station_ids` 为 `null` |

| `error` | 含义 |
|---|---|
| `empty_account` | `account` 为空 |
| `no_such_account` | 账号不存在 |
| `account_disabled` | 账号已停用或已删除 |
| `no_role` | 账号未分配角色 |
| `no_station` | 账号所属部门未对应任何供电所 |

## 6. 附录

### 6.1 预警类型码

| `alert_type` | `alert_label` | `level` | 判据 |
|---|---|---|---|
| `budget_underspend` | 预算预警 | high | 按当前审批速度外推到年底，预计用不到分配的 60% 时报；花得完不报 |
| `zero_execution` | 零审批预警 | mid | 该所当年未审批通过任何项目（县/市级报"几个所零审批"） |
| `approval_backlog` | 待审批积压预警 | high | 状态为草稿 / 提交审核 / 驳回已修改的件数与金额 |
| `node_stay_overdue` | 审批滞留预警 | high | 停在本角色对应审批节点、滞留超 90 天的件数 |
| `node_backlog` | 审批环节积压预警 | mid | 待审批集中在哪个审批环节 |
| `approved_not_started` | 待开工预警 | mid | 审核通过待施工、且已超 30 天未开工 |
| `extreme_amount` | 金额异常预警 | mid | 单笔预算 ≥100 万（需人工核实） |
| `data_quality_amount` | 金额存疑预警 | mid | 工程费或物资费为 0 |
| `data_quality_status` | 状态未登记预警 | low | 状态在原系统未登记，无法计入统计 |
| `data_quality_missing` | 数据缺失预警 | low | 未填计划完工日期 |
| `metric_deteriorated` | 指标预警 | mid | 跳闸次数 / 线损率年度同比恶化 |

### 6.2 角色与推送范围

| `role_code` | 角色 | 推送的预警类型 | 单账号最多条数 | 数据范围 |
|---|---|---|---|---|
| `sz` | 供电所所长 | 预算 · 待审批积压 · 审批滞留 · 审批环节积压 · 待开工 · 金额异常 · 金额存疑 | 4~6 | 本所 1 个 |
| `xgscwb` | 县公司财务部 | 预算 · 零审批 · 待审批积压 · 审批滞留 · 审批环节积压 · 指标 | 4~6 | 本县公司下辖所 |
| `cto` | 县公司运检部 | 审批滞留 · 审批环节积压 · 待开工 · 待审批积压 | 2 | 本县公司下辖所 |
| `yxb` | 县公司营销部 | 审批滞留 · 审批环节积压 | 1~2 | 本县公司下辖所 |
| `sgscwb` | 市公司财务部 | 上列全部（全市口径）+ 金额异常 + 数据质量汇总 | 最多 7 | 全市 47 个所 |
| `master` | 市公司领导 | 预算 · 指标 | 最多 2 | 全市 47 个所 |
| `codea` | 录入人员 | 不推送 | 0 | 本所 |
