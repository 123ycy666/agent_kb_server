# 纠错词典 CSV 导入示例（按《纠错词典规范》第 3 节填）

五个文件对应页面「批量导入」里的五个类别，导入顺序：

1. `pinyin.csv` —— 拼音表：汉字 → 声母 / 韵母。名称库里出现的字都要有。
2. `word.csv` —— 单位规则：`suffix_hint` 决定片段里出现哪些词才去名称库匹配，`unit_kind` 决定什么算单位名。
3. `catalog.csv` —— 名称库：只填名称和类别，拼音三列留空，服务端按拼音表现算。
4. `typo.csv` —— 错别字：字面替换，不走拼音。
5. `wordlist.csv` —— 标准词：按拼音把同音错字改成标准词。

验证：导入后点「立即生效」，在「试一句」里输入
`青芸供电所的现损率是多少`，期望输出 `青云供电所的线损率是多少`。

这几个文件是合成示例，不含任何现场地名；现场用真实机构名单替换 `catalog.csv` 即可。
