## 二 规则数据怎么带过去的

本地库（`ad_wf`）里的规则与配置导出成 SQL：

```
pg_dump -d ad_wf --data-only --inserts --on-conflict-do-nothing \
  -t wf_doc -t wf_doc_version -t wf_schedule -t wf_doc_schedule -t wf_param \
  -f deploy/wf_seed.sql
```

上传后导入：

```
docker cp wf_seed.sql kb-postgres:/tmp/wf_seed.sql
docker exec kb-postgres psql -U kb -d ad_wf -f /tmp/wf_seed.sql
```

只带"规则 + 配置"（`wf_doc` / `wf_doc_version` / `wf_schedule` / `wf_doc_schedule` / `wf_param`），
不带走运行数据（`wf_item` / `wf_notify` / `wf_run` / `wf_run_log`）——那些上线后由定时任务自己跑出来。

备份件也在仓库：`docs/06-口径与数据/预警规则文档-20261107.json`（`docs.import_json` 可读）。
