## 目标

后台换成标准智能体后台：左侧九项菜单、页内一层标签页、三种页面模板（列表 / 设置 / 对话），九页一期全做完；删掉七页死代码。技术栈不变（React 18 + antd 5 + @ant-design/x），问数线代码一行不动，预警与规则逻辑不动。

## 根因

现状不成套的根因在**导航与页面按「开发过程」长，没按「使用者的任务」长**：

- 证据：`App.tsx` 挂了 7 个路由，另有 11 个写好没入口的页；`/specs` 一个页面塞了 8 个页签（说明书、资料、目录、上传、检索、评测、冲突、标签），其中 4 个页签的表是空的；技能与知识混在同一页签里，所以「看不到技能管理」；`/inject` 把整条问数线的 13 项输入平铺成一张表，使用者要的是四份能改的材料。
- 为什么：每加一个能力就新写一个 `pages/*.tsx` 并挂一个路由，没有「列表 / 设置 / 对话」三种模板可复用，也没有「一页管一类东西」的边界；于是功能在，页面不成套，十一页写了没入口。
- 所以修法不是补导航，是**先定模板与边界，再按页重写**：模板抽出来（页标题行、URL 同步页签、列表工具栏），页面按 IA 的九项各管一类，死页连同 `api/index.ts` 里的死封装一起删。

## 步骤（每步都要有能跑出 pass/fail 的输出）

1. **后端小接口**（不改问数线）：
   - `GET /api/agent/overview`（今日轮次 / 失败数）— `web/src/pages/Overview.tsx` 用
   - `GET /api/agent/config` 增 `when_not`（工具什么时候别用）与 `model`（模型名 / 步数 / 上下文预算 / 压缩阈值）
   - `GET /api/v1/system/settings`（员工源、存储目录）
   - `api/v1/specs.py` 增 `POST /specs`（写正文新建）、`PUT /specs/{id}`（存草稿）、`GET /specs/{id}/edit`（任何状态读原文）；`secretary/spec.py` 增 `create` / `save_draft` / `edit_view`
   - verify：curl 每条各打一次，状态码 + 关键字段
2. **全局壳**：`main.tsx` 配 antd theme 令牌；`layouts/MainLayout.tsx` 220 侧栏九项 + 右上角用户；`components/ui/Page.tsx`（标题行 + 主操作）、`components/ui/useTab.ts`（`?tab=` 同步）；`App.tsx` 九路由、`index` → `/chat`
   - verify：`npm run build` 通过 + 路由清单
3. **技能页** `pages/Skills.tsx`：列表（名称 / 什么时候用 / 产物 / 状态 / 更新时间 / 操作）+ 抽屉（名称、角色、什么时候用、适用、产物、正文、检查项）+ 保存草稿 / 发布 / 退役（二次确认）
4. **知识库页** `pages/Kb.tsx`：文档（列表 + 上传 + 看切片）│ 库（只读五库）│ 检索测试
5. **智能体页** `pages/Agent.tsx`：身份与风格 │ 技能 │ 工具 │ 模型；`components/agent/AgentConfigPanel.tsx` 拆成这四个页签用
6. **提示词页** `pages/Prompts.tsx`：问数线四行（口径材料 / 作答规则 / 补问法 / 问题确定）+ 智能体（身份）+ 删「干活线」；编辑器从 `InjectPanels.tsx` 抽到 `components/PromptEditors.tsx`
7. **概览页** 重写 `pages/Overview.tsx`：四个数字 + 最近 10 个会话表
8. **任务页** `pages/Tasks.tsx`（事项 / 运行记录 / 调度，复用 `Workflows.tsx` 里的三个页签）与 **预警页** `pages/Alerts.tsx`（规则 / 记录）
9. **设置页** `pages/Settings.tsx`：模型与端点 │ 员工源 │ 存储 │ 外观（URL 存外观偏好）
10. **对话页视觉**：删顶部那句标语；模型名做成灰色小标签；左栏加搜索框；`记录` 能力并进对话页第二个页签
11. **删死代码**：七页 + 因本次改造不再被引用的（`KnowledgeBaseList.tsx`、`InjectPanels.tsx`、`TaskCenter.tsx`、`Workflows.tsx` 的旧默认导出）；`grep` 确认无引用
12. **验收**：十二条判据逐条跑，证据落 `output/test_results/2026-11-19-后台重构/`，`npm run build` 最后再跑一次
