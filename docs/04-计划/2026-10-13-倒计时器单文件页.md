# 倒计时器单文件 HTML 页 实施计划

> **For agentic workers:** 单任务小交付，按步骤勾选执行。

**Goal:** 交付 `D:\秘书智能体\output\eval-2\index.html` —— 一个零依赖单文件倒计时器：自定义分钟数、开始/暂停/重置、到点提示。

**Architecture:** 一个自包含 HTML 文件（内联 CSS/JS，无外链、无网络请求）。计时核心是纯函数 + 单调时钟累减（`performance.now()` 增量），不靠"每秒减一"，所以掉帧/后台节流都不漂移。UI 由 `render()` 单点驱动。

**Tech Stack:** 原生 HTML + CSS + ES2020，浏览器原生 `requestAnimationFrame` / `Notification` / `AudioContext`。零第三方依赖。

## Global Constraints

- 单文件、零依赖：不得出现任何 `<script src>` / `<link href>` / 网络请求 / CDN。
- 分钟输入支持小数（如 0.1 = 6 秒），便于验收。
- 不用 `alert()` 阻塞弹窗；提示用页内横幅 + 声音 + 标签页标题。
- 无障碍底线：有 `aria-live` 状态区、按钮可键盘操作、`prefers-reduced-motion` 降级。
