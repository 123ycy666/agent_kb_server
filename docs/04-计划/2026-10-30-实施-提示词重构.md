# 实施：提示词重构 + 规则外置 + 个人文档生效（2026-10-30）

> 按 `docs/03-设计/2026-10-30-提示词设计-最终版.md` 落地。**每阶段独立可回滚，每阶段跑测试。**

## 目标

1. 补回「谁说了算」（S1），作答格式进 system（S4），表目录降级为「清单常驻 + `describe_table` 按需」。
2. 规则不再靠向量检索：规则主题目录常驻 + `get_rule` 精确取。
3. 个人文档按 `doc_type` 分规则/资料两条通道生效；个人库不再默认进检索范围。
4. 删死代码（站点包死文件、`answer_data_from_db.md`、`ai_prompt` 旧通道、docgen import 改常量）。
5. 仓库只剩 main 一个分支。

## 根因（本次要改的每一处，都不是"顺手"，是这几条）

| 现象 | 根因 | 证据 |
|---|---|---|
| 提示词 3.1 万字，规则只占 24% | 表目录/码表全量塞进 system | 线上实测 `full=31,295` 字，其中约 2.4 万是表目录 |
| 规则靠 0.18 分检索 | `rule_slices()` 用向量检索判据切片 | trace 里 `rules` 步 `best_score=0.1782` |
| B 端改了不生效 | 两套提示词来源（`ai_prompt` 表 / 站点包 md），V2 只读 md | 线上 `ai_prompt` 表存在但零引用 |
| 站点包"必填"却不进提示词 | `pack['platform']` 全代码零引用 | `redlines.md`/`identity_base.md` 只被装载、从不注入 |
| 部署文件反过来改代码 | `docgen._apply_pack_doc_defaults()` 在 import 时写模块全局 | `docgen.py:173` import 期调用 |
| 个人库配了不生效 | ① 文档传到 kb=1 ② 模型不查库 ③ 无"规则/资料"类型通道 | 线上「我的资料库」0 文档 0 切片；117 轮仅 8 轮调 `kb_search` |
