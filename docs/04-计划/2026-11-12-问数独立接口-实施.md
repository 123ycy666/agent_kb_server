# 问数独立接口（`POST /api/ask/data`）

## 目标

把问数这条链路单独做成一个入口：`POST /api/ask/data` 调用即问数，**只问数**。
现有 `POST /api/ask` 保留为智能体分支：先分线，能问数，也能读文件、出文件、闲聊。

## 判据

| 项 | 判据 |
|---|---|
| 只问数 | `force_data=True` 时不调 `router.route`、不调 `preprocess.route`，工具集恒为 `kb_search / list_metrics / metric_query / run_sql / read_result / finish` |
| 预处理不砍 | 纠错（namefix）、补问法（complete）、问题确定（confirm）照跑，轨迹里三条都在 |
| 不越界 | 不读文件（`read_file` 无）、不出文件（`make_file` 无）、不拟办（`task_draft` 无）、不做大屏跳转 |
| 智能体分支不变 | `force_data=False` 时分线照旧，判到办公线就进 `agent_office` |
| 接口在 | `POST /api/ask` 与 `POST /api/ask/data` 都注册在同一个 router 上 |

## 步骤

1. `server/app/secretary/agent.py`：`ask()` 加 `force_data` 形参，命中即跳过入口分线、把「查库 / 读文件 / 出文件」固定成「是 / 否 / 否」。
2. `server/app/api/v1/agent.py`：原 `/ask` 主体抽成 `_ask_entry(request, actor, force_data)`；新增 `/ask/data` 以 `force_data=True` 调用；两处 `agent_mod.ask(...)`（stream 与线程池）都把该开关传进去；`force_data` 下忽略随附文件并回一条 `doc_warnings`。
3. `server/tests/agent/test_ask_data_lane.py`：假模型驱动 `agent.ask()`，验上面五条判据。
4. 文档 `docs/01-接口/2026-11-12-问答与文件接口.md` 补一节。
