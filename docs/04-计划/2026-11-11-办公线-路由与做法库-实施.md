# 办公线 + 入口路由 + 做法库 —— 实施计划

- 日期：2026-11-11
- 状态：执行中（Fred 要看真实材料的效果与历史记录）
- 根因：入口层把「办事题」当成「问数题」送进 2–6 步预处理，交付物要求在那一步被压成一句话问题；办公能力没有自己的线、没有做法来源（`make_file` 的 `fmt` 恒为空）、没有结构探查手（`describe_table/find_column/list_tables` 未进工具集）。

## 一、目标

1. 入口加一层路由器，只负责分线；**查数线（2–6 步预处理 / 证据包 / 对账 / 写正文）一行不动**。
2. 新建办公线：取做法 → 计划卡 → 工具循环（含 `run_sql`）→ 自检 → 产物卡。
3. 四类做法作为文档入库（`doc_type='howto'`）：文章速读、Excel 处理、文章纠错、公文格式。公开可见，属"额外配置"。
4. 端到端验收用 Fred 桌面真实材料，结果写进 `t_chat_*` 历史记录。
