## 三、健康检查与立即回滚

| 现象 | 判断 | 处理 |
|---|---|---|
| `/health` 非 200 | 服务没起来 | `deploy.sh` 已自动回滚到 `kb-merged:prev`；仍不行看 `docker logs kb-merged --tail 200` |
| `/health` 200 但问答报 500 | 库结构没跟上 | 重跑 `v5_online.sql`（幂等）；再不行回滚库（下一条） |
| 页面白屏 | 前端 dist 没跟上 | 重新 `npm.cmd run build` + `pack.sh` + `push.py` |
| 数据异常 | 结构问题 | `docker exec -i kb-postgres pg_restore -U postgres -d ad_new --clean --if-exists < /tmp/ad_new_before_v5.dump` |

**回滚代码**：`deploy.sh` 失败会自动回滚镜像与目录；手动回滚：
```bash
ssh root@47.121.183.81 "cd /root/agentkownlg && ls -d _deploy_bak_* | tail -1"
# 目录改回备份、docker tag kb-merged:prev kb-merged:latest、restart
```

**回滚库结构（本机/线上同脚本）**：`python db/rollback_v5.py`（视图→删视图→表搬回 public）。
