# 功能总表 + 扩展规范（第一期配套）

- 日期：2026-10-21 ｜ 分支：`feat/agent-v2-modes`
- 配套：`2026-10-21-实施总计划-第一期.md`（那份讲"重构"，这份讲"加功能"）
- 一句话：**新功能只许挂在四个扩展点上，任何新功能都不许改 `agent.py` 的主循环。**

---

## 一、怎么加（四条扩展点，先定规矩再谈功能）

| 扩展点 | 加什么 | 要动哪几个文件 | 上线方式 |
|---|---|---|---|
| **E1 工具** | 模型可以主动调用的能力（如 `excel_query`） | ① `server/app/secretary/tools_xxx.py` 写一个纯函数 ② `config/sites/<站点>/capabilities.yml` 登记一行（name / mode / needs / schema / handler） | 登记即生效，**不改主循环** |
| **E2 流水线** | 长任务、要进度、要产物（如做 PPT、批量转 PDF） | ① `pipeline_xxx.py` 实现 `run(file_id, user_id, opts, progress, out_dir) -> {outputs:[...]}` ② `doc_jobs.py` 白名单加 task 名 ③ 前端下拉加一项 | 需要重启 |
| **E3 技能** | 纯提示词类（如"写年度总结"的写法） | ① `config/sites/<站点>/skills/xxx.md` ② `技能触发配置.json` 加一条（触发词 → 文档） | 命中即注入，**不改代码** |
| **E4 站点规则** | 口径、阈值、角色码、部门锚点、词表 | 只改 `config/sites/<站点>/` 下的 yml/md | 重启生效 |

**四条铁律**
1. 主循环（`agent.py` 的 `TOOLS`/`execute`/守卫/`ask`）**永远不改**；新能力一律通过 E1–E4 挂。
2. 一条功能不许同时改两个扩展点——要么是工具，要么是流水线，别混。
3. 每个新功能必须带一条可判真假的验收（见下表"验收"列）。
4. 依赖新库的，先写进 `requirements.txt` 并确认**内网离线 wheel** 能带进去，否则不准开工。

## 四、这份表和"重构"的关系

| 重构（P0–P3） | 这份表（功能） |
|---|---|
| 让代码只留产品骨架、规则可换包 | 让 agent 会干更多的活 |
| 不改主循环是**约束** | 挂 E1–E4 是**路径** |

**顺序不能反**：先把 P0（站点包 + 七层提示词）落了，后面每加一个功能才只需要"加一个文件 + 登记一行"；反过来的话，每加一个功能又要进主循环改一次，越改越乱。

### 根因记录（P0 调试，2026-10-21）

**R1 模式键名多带了 `.md`**：`site_pack.load()` 用 `m.replace('mode_','')` 取模式键，得到 `general.md`，
`prompt_stack` 查 `general` 取不到 → L2 整层丢失（测试报 `'L2' is not in list`）。
根因：把"文件名"当"键名"用。改：`.replace('.md','')`。

**R2 占位标记没被检测**：`【待导入】` 检查只写在 `take()` 里（平台/站点必填文件），
而 `prompts/*.md` 是另一条读取路径，绕过了检查 → 严格模式放行、`placeholders` 为空。
根因：同一类检查写了两处读取路径，只补了一处。改：在 prompts 循环里同样检查。

**R3 占位路径标签取错变量**：记录为 `prompts/prompts/business_rules.md`（`base.name` 是 `prompts` 这一级），
应为 `suizhou/prompts/business_rules.md`。根因：站点名在 `base.parent.name`，取了子目录名。
改：`base.parent.name`。

**R4 判"写工作总结"落到 general**：`objects` 词表里没有"总结/材料/讲稿/汇报/说明"。
根因：词表是我拍的，漏了最常用的几个。改：补进 `mode_rules.yml`（顺带证明"词表可配置"这条设计是对的——
补词只改 yml，不动代码）。

**R5 S1 判据改成两段**：P0 阶段老代码仍有 50 处单位名（P3 才外置），要求"全清"会让 P0 永远红。
改：P0 只断言**新增三模块**无单位名，老的作为遗留项打印计数，P3 收口。
