# 对话项目接入知识库 · 调用示例

> 目标：你的另一个「对话项目」不再自己造知识，而是把问题抛给本知识库，
> 由它做**向量召回 + 重排 + RAG 生成**，直接拿回带引用的答案。
>
> 线上地址：`http://47.121.183.81/api/v1`　｜　接口文档：`http://47.121.183.81/docs`

---

## 一、两条路，先选一条

| 方案 | 接口 | 返回 | 适合 |
|---|---|---|---|
| **A. 直接问答（推荐）** | `POST /chat` | `answer`（LLM 生成的答案）+ `citations[]` | 你只想"问一句、拿答案"，不想自己接 LLM |
| **B. 只取资料** | `POST /search` | 命中的**切片原文** + 分数，不带答案 | 你想用**自己的模型/Prompt** 生成，只借它的检索 |

> 两者 body 结构**完全一致**，切换零成本。

---

## 二、三个硬性前提（踩坑点）

1. **必须用 IP 访问**：nginx 的 `server_name` 是 `47.121.183.81`。
   用域名或 `127.0.0.1` 会落到默认站 → **502**。
2. **认证只有一条路**：`POST /auth/login` 拿 JWT，之后所有请求带
   `Authorization: Bearer <token>`。**应用令牌（`kb_live_*`）已于 2026-10-12 移除**。
   JWT **12 小时过期** → 调用方必须实现 **401 自动重登**。
3. **跨域**：若你的对话项目跑在浏览器里且不同源，需要把来源加进知识库的
   `CORS_ORIGINS` 白名单（当前只有 `http://47.121.183.81`）。
   服务端调用无此问题。

## 三、Python 客户端（可直接用）

```python
import httpx

class KBClient:
    """知识库对接客户端：登录 → 缓存 token → 401 自动重登。"""

    def __init__(self, base="http://47.121.183.81/api/v1",
                 username="integration", password="<管理员分配的密码>"):
        self.base, self.user, self.pwd = base, username, password
        self.token = None
        self.http = httpx.Client(timeout=120)

    def _login(self):
        r = self.http.post(f"{self.base}/auth/login",
                           json={"username": self.user, "password": self.pwd})
        r.raise_for_status()
        self.token = r.json()["access_token"]

    def _post(self, path, body):
        if not self.token:
            self._login()
        r = self.http.post(f"{self.base}{path}", json=body,
                           headers={"Authorization": f"Bearer {self.token}"})
        if r.status_code == 401:          # ⚠️ token 过期 → 重登一次再试
            self._login()
            r = self.http.post(f"{self.base}{path}", json=body,
                               headers={"Authorization": f"Bearer {self.token}"})
        r.raise_for_status()
        return r.json()

    # ── A. 直接问答（知识库自己生成答案）──────────────────
    def ask(self, question, kb_ids, top_k=5):
        return self._post("/chat", {"query": question, "kb_ids": kb_ids,
                                    "top_k": top_k, "rerank": True})
        # 返回 {"answer": "...", "citations": [{index, doc_name, snippet, ...}]}

    # ── B. 只取资料（用你自己的模型生成）──────────────────
    def search(self, question, kb_ids, top_k=5):
        return self._post("/search", {"query": question, "kb_ids": kb_ids,
                                      "top_k": top_k, "rerank": True})
        # 返回 {"results": [{content, parent_content, rerank_score, doc_name, ...}]}


if __name__ == "__main__":
    kb = KBClient()
    res = kb.ask("公司弹性工作制的上班时间怎么规定的？", kb_ids=[3])
    print(res["answer"])
    for c in res["citations"]:
        print(f"  [{c['index']}] {c['doc_name']}")
```

## 四、把「对话项目」的 Prompt 拼起来（方案 B 用）

```python
hits = kb.search(user_question, kb_ids=[3, 5], top_k=5)["results"]

context = "\n\n".join(
    f"[{i+1}] 来源：{h['doc_name']}\n{h['parent_content']}"   # parent_content = 同章节上下文
    for i, h in enumerate(hits)
)

messages = [
    {"role": "system",
     "content": "你是公司助手。只依据下面【资料】回答，资料没有就说不知道，"
                "并在句末用 [1][2] 标注引用来源。"},
    {"role": "user", "content": f"【资料】\n{context}\n\n【问题】{user_question}"},
]
# ... 再丢给你自己项目的 LLM
```

> 💡 **优先用 `parent_content`（父块）而不是 `content`**：`content` 是切片本身，
> `parent_content` 是同章节完整上下文，喂给 LLM 信息更全。

## 五、流式输出（前端打字机效果）

`POST /chat` 传 `"stream": true`，响应 `Content-Type: text/event-stream`（SSE，`chunked`）。

**⚠️ 报文格式不是 OpenAI 风格**，事件名是自定义的（线上实测）：

```
event: citations
data: [{"index":1,"chunk_id":221,"doc_name":"工作时间.docx","snippet":"…","parent_content":"…"}]

event: delta
data: {"content": "根据"}

event: delta
data: {"content": "资料 [1]：…"}

event: done
data: {}
```

| 事件 | data | 说明 |
|---|---|---|
| `citations` | **数组** | 首帧一次给全引用（先渲染"来源"区） |
| `delta` | `{"content": "片段"}` | 逐块推正文，**累加**即完整答案 |
| `error` | 错误 JSON | 生成中断 |
| `done` | `{}` | 结束标记 |

```js
const resp = await fetch("http://47.121.183.81/api/v1/chat", {
  method: "POST",
  headers: { "Authorization": `Bearer ${token}`, "Content-Type": "application/json" },
  body: JSON.stringify({ query: q, kb_ids: [3], stream: true })
});

const reader = resp.body.getReader();
const decoder = new TextDecoder();
let buf = "", evt = "";

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  buf += decoder.decode(value, { stream: true });

  let idx;
  while ((idx = buf.indexOf("\n\n")) !== -1) {   // SSE 以空行分隔事件
    const block = buf.slice(0, idx);
    buf = buf.slice(idx + 2);

    let event = "message", data = "";
    for (const line of block.split("\n")) {
      if (line.startsWith("event:")) event = line.slice(6).trim();
      else if (line.startsWith("data:")) data += line.slice(5).trim();
    }
    if (!data) continue;
    const payload = JSON.parse(data);

    if (event === "citations") renderSources(payload);        // 数组
    else if (event === "delta") appendToUI(payload.content);   // 逐字上屏
    else if (event === "done")  finish();
    else if (event === "error") showError(payload);
  }
}
```

## 六、响应字段速查

`POST /search` 每条结果：

| 字段 | 含义 |
|---|---|
| `content` | 切片正文（**已带 `【标题路径】` 前缀**） |
| `parent_content` | **同章节父块**上下文（喂 LLM 用这个） |
| `rerank_score` / `fused_score` | 重排分 / 融合分（排序依据） |
| `doc_name` / `doc_id` / `chunk_id` | 来源定位 |
| `has_conflict` | 该切片是否涉冲突 |
| `tags` | 标签 |

`POST /chat`：`answer`（markdown 文本）+ `citations[]`（`index` / `doc_name` / `snippet` / `parent_content`）。

## 七、常见错误对照

| HTTP | code | 原因 / 处理 |
|---|---|---|
| 401 | `BAD_CREDENTIALS` | 账号密码错 |
| 401 | — | token 过期（12h）→ 重新登录 |
| 404 | `KB_NOT_FOUND` | `kb_ids` 里的库不存在或无权限 |
| 502 | — | 用了域名/127.0.0.1 访问，改回**公网 IP** |
| 200 但 `results` 空 | — | ①库内无相关文档 ②`tag_filters` 过滤太严（看 `filter_notice`）③该文档对你不可见（private 非本人） |

## 八、两点提醒

- **目前是纯 HTTP，无 HTTPS**：账号密码与 JWT 明文过公网。公网对接建议后续补 HTTPS。
- **知识库侧的模型已换成阿里云百炼 `deepseek-v4-flash-0731`**，你这边**不用做任何改动**，
  它只影响"答案由谁生成"。
