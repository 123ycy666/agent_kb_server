# 数据地图：想查什么，大概去哪张表

这份文件回答"我要的数据大概在哪张表"。表名与注释都来自业务库 dlj_data 实测（133 张表）。
口径与公式见同库的《口径库》；本文件只负责"去哪找"。

## 一、先看这几条

1. 表名前缀有含义：t_power_push_* 是中台推送的月度/年度汇总（最常用、最干净）；
   t_power_* 是业务明细与台账；t_cost_* 是成本定额与物料价；stg_* 是暂存表（通常为空，别用）；
   *_bak_* / *_copy* / *_ago_img_* 是备份或历史副本，**不要当数据源**。
2. 表注释（中文）是判断用途的第一线索，先 list_tables 按关键词筛，再 describe_table 看字段。
3. 汇总类数据（线损率、停电时长、工单量、售电量）优先看 t_power_push_*_month_summary / _year_summary，
   不要从明细表自己加总，除非口径库明确要求。
4. 估算行数是 InnoDB 估算值，可能严重偏离（有的估算 25 万实际 0 行）。**用前先 COUNT 一次**。
