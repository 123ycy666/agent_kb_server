## 0. 前置检查（⚠️ 不通过就别往下走）

```bash
# 磁盘：需 ≥10G 可用（当前仅 2.9G，先清理或挂数据盘）

# 内存：需 ≥2G 可用（当前仅 1G，先查谁占了 6G）
```

- 🟠 内存紧张 → compose 已给各服务设 `mem_limit`、worker 并发=1；仍不足就关无用进程或加 swap

## 3. 构建并启动（在服务器执行）

```bash
cd /root/agentkownlg/kb

# 首次：构建镜像并启动四个服务（PG + Redis + 后端 + worker）

# 查看状态：四个都应是 running；postgres/redis/backend 应 healthy
docker compose -f docker-compose.prod.yml ps

# 看日志

docker compose -f docker-compose.prod.yml logs -f worker
```

> ⚠️ `pgvector:pg16` 镜像服务器已有，不会重复拉取。
> ⚠️ **worker 必须 running**，否则上传后一直停在「处理中」。

## 5. nginx 收口（对外入口）

```bash
# ① 拷站点配置到宿主机 nginx
cp /root/agentkownlg/kb/deploy/nginx/kb.conf /etc/nginx/conf.d/kb.conf
#   改 server_name 与 root 路径

# ② 语法检查后重载
nginx -t && systemctl reload nginx

# ③ 若用 HTTPS（服务器能出网）
certbot --nginx -d kb.example.com
```

**⚠️ 关键点 1（路径冲突）：** 现网已有 `location /api/ → 127.0.0.1:11999`，本系统用**独立域名** +
更具体的 `location /api/v1/`，两处避免冲突。务必先 `nginx -t`。

**⚠️ 关键点 2（`/root` 权限）：** 项目在 `/root/agentkownlg/kb`，而 `/root` 默认权限 `700`，
nginx 工作进程以 `nginx` 用户运行，**进不去 `/root`** → 前端页面会 **403**。放行“进入”权限即可：

```bash
chmod o+x /root /root/agentkownlg /root/agentkownlg/kb /root/agentkownlg/kb/web
chmod -R o+rX /root/agentkownlg/kb/web/dist
```

## 6. 数据迁移（要把本机开发数据搬上去才做）

```bash
# 本地导出
docker exec kb-postgres pg_dump -U kb kb_system > kb.sql
# 服务器导入（先等 postgres healthy）
docker exec -i kb-postgres psql -U kb kb_system < kb.sql
# 上传文件：把本地 data/uploads/ 覆盖进容器卷
docker cp data/uploads/. kb-backend:/data/uploads/
```
> ⚠️ **模型档位切换会导致向量失配**：本地 `mock` → 服务器 `online` 时，
> 旧向量全部作废，导入后必须跑重建索引：
> `docker exec kb-backend python scripts/rechunk_documents.py --apply`

## 7. 常见坑速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 前端能开、一登录就报错 | `/api/` 被现网规则截胡 | 用独立域名 / 检查 `/api/v1/` 反代 |
| 上传后一直「处理中」 | worker 没起 | `docker compose ps` 看 kb-worker |
| 检索返回空 | 模型档位与向量不匹配 | 切档后跑 `rechunk_documents.py --apply` |
| 上传大文件 413 | nginx 限制 | `client_max_body_size 100m` |
| 中文文件名乱码 | 容器 locale | Dockerfile 已设 `LANG=C.UTF-8` |
| 浏览器 CORS 报错 | 前端域名未加白 | `.env.production` 的 `CORS_ORIGINS` |
| 重启后数据没了 | 未挂卷 | 已用 `kb_prod_*` 命名卷，检查 `docker volume ls` |

## 8. 日后迁内网（差异仅三点）

1. **镜像**：内网不能拉 → 本地/外网 `docker save` 打包 tar，内网 `docker load`
2. **模型档位**：改 `PROVIDER_MODE=local`（内网模型）或 `mock`（仅演示）
3. **依赖**：内网无 `pip` 源 → 预先 `pip download` wheel 包离线安装

其余步骤（compose 起服务、nginx、验证）**完全一致**；消费方（智能体/前端）**只改 baseURL**。
