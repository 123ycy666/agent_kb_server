# 题目清单（72 场景 + 6 独立问题）

## 用法

1. 每题**照原话问**（残缺、口语），不替系统补全 —— 这样才看得到补全效果。
2. 文档里每题三行：**原话 → 系统补全后 → 回答**。
3. 补全口径按《判据规则》19.1：时间没说 → 用统计范围；范围没说 → 用提问人身份范围；对象没说 → 用默认对象；第 2 轮起沿用上一轮对象与范围。
4. 对象用真实数据：47 个供电所、4 个县公司、真实线路与台区名。

## 维度一 预算分配（20）

**1 环潭 · 收到分配通知（所长）**
环潭这次分了多少？ → 比上回多还是少？ → 咋分这么多？ → 跟第一的差哪？ → 该治啥、钱花哪？ → 出个能报的计划 → 明年想提高预算该咋办？（要给路径和预期成效）

**2 唐镇 · 年中被催进度（所长）**
