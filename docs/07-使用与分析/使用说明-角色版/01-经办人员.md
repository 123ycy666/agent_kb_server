# 小智使用说明 · 经办人员（工单录入与办理）

## 一、问数：能查哪些数

1. 这一单的现状：当前状态、工程费与物资费各多少、已经过哪些节点、每个节点停了几天、现在在谁手上。
2. 本所还能报多少：当年分配额、已审批金额、剩余可用额。
3. 同类单往年怎么报的：同类缺陷或项目的件数、单件金额区间与中位。
4. 台区与线路的底数：用户数、线损率、用户平均停电时间、跳闸次数、往年治理记录。
5. 这一单有没有被驳过、驳回原因是什么、同批被驳的还有几单。
6. 这类单要过几个审批节点、每个节点历史上平均停几天。

## 二、分析：能问哪类问题

1. 这单报多少合适：给出同类单件金额区间与中位，指出所报金额偏离多少、建议调到多少。
2. 这单会不会超本所可用额：给出剩余可用额、超出多少、拆成几张能报。例：本所余额 48.20 万，这单报 50 万，结论「超 1.80 万」，并给出拆法。
3. 现在报来不来得及：按各节点历史停留天数估算批完要几天，年内能否批完并完工。
4. 被驳了怎么补：按驳回原因逐条列出要补的材料、要改的字段。
5. 同一台区、同一线路往年治过什么、花多少钱、治完指标降没降。

## 三、预警与任务：收到什么、怎么处理

1. 预警不发到本岗位：预警按角色推送，录入与执行岗的「我的预警」为空，属岗位设置。
2. 派到本岗位的任务长什么样：任务编号、标题、要求原文、来源（某条预警或某位领导点名）、承办人（主责 / 协办 / 抄送）、回执时限、完成时限、当前状态与时间线。实测一条：标题「把结余项目在限期内报审完」，要求「本周内把卡在草稿的单子提交审批，完成后回执」。
3. 时间怎么定：回执时限按级别 24 / 72 / 168 小时（实测默认 1 天），完成时限默认 30 天，下发时可改。
4. 处理流程：接单 →（要求提交方案的）交实施方案 → 发起人确认，通过或驳回都会通知 → 办理 → 提交办理结果并上传证明材料 → 状态转「待核销」→ 能按数据核对的自动核销（如预算执行率回到 60% 以上），不能自动的由发起人确认关闭。
5. 方案不用自己想：任务一到即可取实施方案草稿，实测给的是「第 1–3 天核对余额与可立项对象；第 4–10 天形成 2–3 个项目建议书并走审批；第 11–30 天跟踪审批进度，每周回报执行率变化」，改完提交。
6. 催办：到期前 4 小时提醒，逾期催办并按职责线上报。

## 四、报告：帮你写材料

1. 读通知：上级通知读成一页纸要点加待办清单（谁办、什么时候办完、要报什么材料），可导出 Word 与 Excel。
2. 审材料：错别字、用词不当、标点与数字用法、层次序号、病句与前后矛盾，逐条给「原文、建议、依据、位置」。
3. 查表格：空值、重复行、合计不平、单位混写、文本数字、日期混用，定位到具体工作表与单元格。
4. 起草：情况说明、上报报告、处置情况报告（基本情况、问题与依据、已采取措施、结果与下一步），可导出 Word。

## 五、功能

1. 问数
2. 分析
3. 任务办理
4. 材料审查
5. 表格查错
6. 文件速读
7. 材料起草
8. 处置情况报告

## 六、使用限制

1. 小智不修改业务库里的数据，也不代替用户在业务系统中提交工单。
2. 小智不替用户定类别、定金额、定批不批，只给依据和建议。
3. 业务库里没有的数据，小智给不出，只回「未查得」，不估算。
4. 小智看不到本所以外的数据，范围按岗位定。
5. 扫描件（没有文字层）与 .doc / .wps 旧格式读不了，需另存为 .docx。
