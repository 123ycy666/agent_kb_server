# 设计：地点解析改三态（认出 / 明说全市 / 认不出要说出来）

日期：2026-11-02
触发：上一问「两水供电所」，下一问「曾都供电所」，答案还是两水的。

## 根因（已实测，确定性复现）

`time_scope.place_of()` 认不出地点时返回空串，`describe()` 把空串理解成"这轮没说地点"，
于是沿用上一轮的 `prev['place']`。服务器实测（`prev=两水供电所`）：

```
曾都供电所 / 曾都供电所情况怎么样 / 曾都所 / 曾都所呢 / 曾都那边 / 曾都的情况
    → 全部「两水供电所」★沿用
曾都 / 曾都区 / 曾都区供电公司 / 国网曾都区供电公司
    → 正确认出「国网曾都区供电公司」
```

因为名录（51 条，来自纠错词典 `t_nc_typo`）里**没有「曾都供电所」**，只有
「国网曾都区供电公司」，简称是「曾都区」—— 差一个「区」字就整条落空。
所以不是偶然：**说了单位名但名单里没有，就必然套上一轮的地点**。

## 目标

1. 本轮问题**提了地点**就绝不用上一轮的地点。
2. 认不出时**不许静默**：要么认出（靠别名/维表），要么把"没认出"写进口径让人看见。
3. 台区识别不再是死代码。

## 边界 / 不改什么

- 不动时间解析（`resolve`）、不动补全表、不动四份规则材料、不动提示词。
- 不改 `t_nc_typo` 的**纠错**职责 —— 只是不再拿它当单位名录。
- 不动多轮沿用本身：真没提地点时照旧沿用（这是对的）。

## 改法

### ① 解析出三态，而不是"空串表示没提"

`place_of` 旁边加一个判据 `looks_like_place(question) -> bool`：
问题里出现**像单位名的串**（`XX供电所 / XX所 / XX公司 / XX站 / XX区 / XX县 / XX镇 / XX村`
或命中名录）。`describe()` 的空地点分支改成：

| 情况 | 处理 |
|---|---|
| 认出了地点 | place = 那个地点，`inherited=False` |
| 问题里明说全市 | place = 全市，`inherited=False` |
| 像单位名但没认出 | **不沿用**；place 留空 + `need_confirm=True`，口径里写「本轮提到「曾都供电所」，系统没认出这个单位，先确认是哪一个，不要沿用上一轮」 |
| 完全没提地点 | 沿用上一轮（现状不变） |

改完 `scope` 结构多两个字段（`inherited['place']` 已有，新增 `confirm`），
`agent.py` 把它交给模型的【统计范围】里加一句，trace 里也记一笔，排障能直接看到。

### ② 名录换源 + 一跳别名

- `_units()` 改读业务库单位维表（`t_power_company` + `t_power_supply_company`，走 `tools_db`），
  读不到再回退现在这份纠错词典名单。
- 认不出时补一跳：`XX` → 试 `XX区 / XX县 / XX市`；`XX所` → 试 `XX供电所`。
  「曾都」→「曾都区」这一跳就是现在缺的。

### ③ 删死代码

`place_of()` 里 `from app.secretary import object_index` —— 这个模块**整个仓库不存在**，
ImportError 被 `except: pass` 吃掉，注释里说的台区兜底从没生效。二选一：
补一个真模块，或把这段删掉（台区改用业务库台区表判）。倾向**先删**，等台区需求确实出现再补。

## 验收判据（确定性，不靠"偶然"）

新增 `server/tests/agent/test_place_scope.py`，不用数据库也能跑（名录注入替身）：

1. `曾都供电所 / 曾都所 / 曾都所呢 / 曾都那边 / 曾都的情况` → **绝不等于**上一轮地点，
   且 `confirm=True`。
2. `曾都 / 曾都区 / 曾都区供电公司` → `国网曾都区供电公司`，`inherited=False`。
3. `情况怎么样` / `那售电量呢`（真没提地点）→ 沿用上一轮，`inherited=True`。
4. `全市 / 市局 / 各所` → 全市，不沿用。
5. `两水 / 洛阳 / 环潭` 带不带「供电所」→ 一律认出对应所。
6. 名录为空（维表读不到）→ 不崩，且仍然"认不出就不沿用"。

再加一条线上核对：`agent.ask()` 连问「两水供电所情况怎么样」→「曾都供电所情况怎么样」，
trace 里第二轮必须是 `place_inherited=false`。

## 风险

- `looks_like_place` 判太宽会把"情况怎么样"当单位名 → 误判成"需要确认"。所以它的词表
  只认**明确形态**（所/公司/站/区/县/镇/村 + 长度≥2 的前缀），并用上面第 3 条用例钉住。
- 名录换成维表后，维表没数据的环境要能回退（第 6 条用例）。
