## 二、监测与升级：谁盯着谁

```mermaid
flowchart LR
  subgraph BUD["预算线"]
    direction LR
    B1["所长 sz"] --> B2["县财务 xgscwb"] --> B3["市财务 sgscwb"]
    B3 -.->|"只收汇总"| B4["市领导 master"]
  end

  subgraph PRJ["项目线"]
    direction LR
    P1["所长 sz"] --> P2["县运检 cto / 县营销 yxb"]
    P2 -->|"市公司无对口角色<br/>不硬塞领导"| P3["发起人 + 管理员<br/>标「待指定」"]
  end

  subgraph IDX["指标线"]
    direction LR
    I1["所长 sz"] --> I2["线损/跳闸/停电 → 县运检 cto"]
    I1 --> I3["售电量/意见工单 → 县营销 yxb"]
    I2 --> I4["市财务 sgscwb"]
    I3 --> I4
  end

  subgraph RVW["复盘线"]
    direction LR
    R1["县财务 xgscwb"] --> R2["市财务 sgscwb"]
    R2 -.->|"年度结论"| R3["市领导 master"]
  end
```

| 监测点 | 谁在监测 | 判断 / 动作 |
|---|---|---|
| 有没有异常、预警是否恢复 | **系统 cron** | 命中建/更新预警；不再命中 → `resolved` |
| 这句话是不是"要办一件事" | **语义分类器 + 人** | 模型判意图/置信度；人回「确认」才建任务 |
| 任务该谁办 | **系统推荐 + 发起人** | 范围+角色找人；找不到往上找 / 标待指定 |
| 回执有没有交 | **系统 tick** | 提前 4h 提醒；超期每 24h 催 |
| 超时要不要升级 | **系统 tick** | 宽限期后升一级；每天最多一次；≤2 级 |
| 任务办得怎么样 | **发起人 / 上级** | 审方案、看回执与附件 |
| 数据有没有变好 | **系统 tick** | 自动核销；数据取不到 → 转人工，不静默闭环 |
| 承办人还在不在 | **系统 tick** | 停用/离职 → 同部门同角色转派 |
| 草稿没人确认 | **系统 tick** | 7 天自动作废 |
| 闭环后归档 | **发起人 + 系统** | 7 天内可重开；归档后列表隐藏、时间线保留 |

## 三、任务状态机

```mermaid
stateDiagram-v2
    [*] --> draft: 对话/预警拟稿
    draft --> open: 人确认（或下发）
    draft --> cancelled: 取消 / 7天过期
    open --> doing: 主责接单
    open --> open: 拒接（升级+1）
    open --> cancelled: 发起人撤回
    doing --> verify: 提交回执
    verify --> closed: 自动达标 / 发起人确认
    verify --> doing: 驳回
    doing --> cancelled: 发起人撤回
    verify --> cancelled: 发起人撤回
    closed --> doing: 7天内重开
    closed --> [*]
    cancelled --> [*]
```

> `escalate_level`（0→1→2）、`overdue_flag`（0/1）、`archived_flag` 是**标志位**，不新增状态；
> 非法迁移（如 open 直接 closed）一律 409 拒绝。

## 四、运行参数（线上实际值）

| 项 | 值 |
|---|---|
| 扫描 | 每日 8:00（预算+项目）、周一 8:20（周）、每月 5 日 8:30（指标+复盘）、1/7 月 1 日 8:40（复盘） |
| tick | 服务内嵌循环，**每 10 分钟**（`DISPATCH_TICK_MINUTES=10`） |
| 回执时限 | 高 24h / 中 3 天 / 低 7 天（发起人可改） |
| 完成时限 | 默认 30 天；预算类可设月底/年底 |
| 催办 | 回执前 4h 一次；超期后每 24h 一次 |
| 升级 | 宽限期后每天最多一级，上限 2 级 |
| 草稿 | 7 天未确认自动作废 |
| 自动核销 | 每轮 tick 实测；数据取不到 → 不闭环，转人工 |
