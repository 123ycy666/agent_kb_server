## 二、一次请求的完整链路

| 步骤 | 做什么 | 落在哪 |
|---|---|---|
| 1 | 登录态、角色、可见范围 | 入口层 |
| 2 | 装载会话（含 L4 人设） | 会话表 |
| 3 | 判模式（规则优先；判不出落 general） | `modes.py` |
| 4 | 装配提示词：L0→L1→L2→(L3)→L6→L4→L5 + 冲突声明 | `prompt_stack.py` |
| 5 | 取工具集（按模式 + 模型预算） | `capabilities` |
| 6 | 循环调用模型与工具（`tool_choice=auto`） | 编排层 |
| 7 | 后处理：数字回指校验 → 不过就拦下重答 | 守卫 |
| 8 | 落库：问题、口径、工具轨迹、答案、质量标记、用量 | `qa_log` |
| 9 | 出产物（如 PPT/Word）→ 任务化异步 → 下载 | `doc_jobs` |

**关键改动在第 6/7 步**：从"先强制查库再答"改成"该查就查、不该查直接答"，把防线从**过程强制**移到**结果校验**。

## 三、七层提示词栈（规则不在代码里）

| 层 | 内容 | 载体 | 谁能改 | 注入条件 |
|---|---|---|---|---|
| L0 红线 | 数字必须有出处、不许编造、不许越权、不许泄露他人数据 | **代码常量** | 无人 | 永远 |
| L1 身份 | 本单位身份（含 `{SITE_NAME}`） | `_platform/identity_base.md` + 站点 `prompts/identity.md` | 实施 | 永远 |
| L2 模式 | 四种模式各自的做法 | `_platform/mode_*.md` | 实施 | 按模式 |
| L3 业务口径 | 时间默认年、草稿排除、金额万元、SQL 规范、工单规则、作答要求 | 站点 `prompts/*.md`（现有 5 道搬入） | 实施/运维 | **仅 data/doc** |
| L6 个人偏好 | 文风、字体、落款 | `t_user_pref` | 员工 | 出文档时 |
| L4 会话人设 | "你是我的参谋长" | `t_chat_session.persona_*` | 员工 | 该会话 |
| L5 技能 | 技能说明书 / 办公技能包 SKILL.md | 站点包 / 技能包 | 管理员 | 命中时 |

冲突声明写在最前：**序号小的优先**（L0 > L1 > L2 > L3 > L6 > L4 > L5）。

## 六、多单位形态（当前最重要的可扩展性）

```
                     ┌──────────────┐
    .env SITE=suizhou│ site_pack.py │──► config/sites/suizhou/   （随州：业务规则、口径、锚点、词表）
    .env SITE=xiantao│              │──► config/sites/xiantao/  （仙桃：只换包）
                     └──────┬───────┘
                            │ 与 _platform/ 合并（红线与骨架不可被站点覆盖）
                            ▼
                      prompt_stack → 同一套代码
```

- 换单位：放一个目录 + 改 `SITE` + 重启。**代码零改动。**
- 缺必填文件 → **启动失败并指名**，绝不回落别的单位规则。
- 数据库结构差异：优先用「表/字段中文名映射 → 码表映射 → 兼容视图」三层消化。

## 八、改前 / 改后对照

| 维度 | 现在 | 改后 |
|---|---|---|
| 人格 | 只有一个（业务秘书） | 四种模式，general 可自由作答 |
| 提示词 | 5 道 key 无条件注入 | 七层按模式装配，红线在最上 |
| 查数 | 强制先查再答（`tool_choice=required`） | 该查就查；靠结果校验守住数字 |
| 规则位置 | 散在 11 个 py 文件里 | 站点包（md/yml），代码只留逻辑 |
| 加功能 | 改主循环 / 加 if | 挂 E1–E4 |
| 换单位 | 改代码 | 换包（`SITE=`） |
| 会话 | 一套人设 | 每个会话可另设 |
| 办公能力 | 自写 docx/xlsx | 接别人技能包（Apache-2.0）+ 自检闸门 |

## 九、不变量（无论怎么改都不许破）

1. 数字必须有出处；编造 = 最严重错误
2. 只能用允许的表、只读 SELECT、权限按角色与范围
3. 会话按人隔离；个人数据进不了共享检索
4. 所有操作留审计；产物带"AI 辅助生成，请人工复核"
5. 单进程、离线可跑；模型全部走 HTTP
