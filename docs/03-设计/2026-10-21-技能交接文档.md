## 一、已有技能（能用的）

每条都写清：**用户怎么说 → 走哪里 → 用什么实现的（开源项目/许可）→ 怎么验 → 什么不行**。

### 1. 问数（原有，未改）
- 用户： "环潭所上个月线损多少""哪几个台区合计不平"
- 入口：`/api/ask`（模式 data）
- 实现：自研主循环 + 4 个工具（`kb_search` / `find_column` / `run_sql` / `finish`）+ 四类守卫（时间范围/权限/单位/数字出处）
- 验收：`test_merge_contract`（原有）、3 个老问数问题数字与改前一致
- 不行：**口径靠模型写 SQL**（见 3）

### 2. 核心指标口径兜底（本次新增）
- 用户："预算执行率是多少"
- 入口：同上，代码**预热**（识别到指标问题先按固定口径算好塞进上下文）
- 实现：自研 `metrics.py`，固定 SQL（状态 3/6/7、`create_time`、当年年初至统计日）
- 验收：`test_metrics.py`（16 项）+ 实跑三次 `run_sql=0`、执行率均 0.00%
- 不行：只覆盖"预算执行率"一个指标，其它指标待按同样形状加

### 3. 通用问答 / 写作（本次新增）
- 用户："写一篇 300 字工作总结""写份廉洁从业倡议书""解释一下什么叫线损"
- 入口：`/api/ask`（模式 general，**不挂工具、不塞业务表目录**）
- 实现：自研七层提示词装配（`prompt_stack.py`）+ 站点包身份文案
- 验收：`test_prompt_stack.py`（含"general 的 system 里没有 L3 业务口径"）
- 实测：倡议书 3.6 秒出稿、0 次工具调用；三模型（max/flash/27b）都能出可用稿
- 不行：翻译/润色没有专门技能文档，靠模型自由发挥

### 4. 做 PPT（本次新增）
- 用户："把这份材料做成 PPT"
- 入口：`/api/docs/jobs` `task=deck`，前端下拉「做PPT」
- 实现：**毕昇 bisheng-pptx 技能包**（`dataelement/bisheng`，**Apache-2.0**）的排版纪律 + 交付前自检脚本 `inspect_deck.py`
- 验收：`test_deck_job.py`（10 项）；自检"通过"才交付，不通过直接抛错
- 不行：第一版按标题分页、要点取原文首句（不调模型写要点）；不套企业母版（等模板）

### 5. 写公文 Word（本次新增）
- 用户："按公文版式把这份通知排一下"
- 入口：`task=doc_write`
- 实现：**毕昇 bisheng-docx 技能包**（Apache-2.0）的 `apply_gongwen_defaults` / `setup_page` / `add_page_number_footer` / `enable_update_fields`；体检用 `inspect_docx.py`
- 验收：`test_batch_features.py`（自检通过 + 标题正文 + 页脚声明 + 格式来自站点包）
- 不行：只重排不改写；目录域需在 Word 里 F9 更新

### 6. 文件比对（本次新增）
- 用户："这两版制度哪改了"
- 入口：`task=compare`（需两份文件，`options.other_file_id`）
- 实现：Python 标准库 `difflib`（逐段 SequenceMatcher）+ `python-docx` 出清单
- 验收：`test_batch_features.py`（1 删 2 增、无差异时明确写"没有段落级差异"）
- 不行：段落级粒度，不做语义级"意思变了"

### 7. Excel 直接问（本次新增）
- 用户："这张表里哪几个台区合计不平"
- 入口：工具 `excel_query`
- 实现：`openpyxl`（MIT）读表 → Python 内置 `sqlite3` 查询（只读闸：禁写/禁多语句/超量标记）
- 验收：`test_excel_query.py`（11 项）
- 不行：全量读进内存，单表约 50 万行以内；再大要换 duckdb

### 8. PDF 处理（本次新增）
- 用户："把这几份 PDF 合成一份""拆成单页""抽第 2、4 页"
- 入口：工具 `pdf_tool`
- 实现：**pypdf**（BSD）
- 验收：`test_pdf.py`（15 项，含加密/非 PDF 报错）
- 不行：加密 PDF 要人工先解密

### 9. 看图（本次新增）
- 用户："图里写了什么""这张照片是什么场景"
- 入口：`vision.describe()`（接口待接前端）
- 实现：**qwen3-vl-plus**（阿里云百炼，OpenAI 兼容协议）；图片直传 base64，不落盘
- 验收：`test_vision.py`（11 项，真调接口：本地生成的图读出了 `¥48.20`，916ms）
- 不行：PIL 默认字体渲染不出中文（真实截图/照片不受影响）

### 10. 批量作业（本次新增）
- 用户："这 20 份一起处理"
- 入口：`POST /api/docs/jobs/batch`
- 实现：自研 `doc_jobs.batch_create()`（每份一个任务，单份失败不影响其它）
- 验收：`test_batch_jobs.py`（12 项，含并发上限保护）
- 不行：并发上限同账号 3 个在跑

### 11. 定时任务（本次新增）
- 用户/运维："每天早上 8 点跑一次 xx"
- 入口：站点包 `jobs.yml`
- 实现：**APScheduler**（MIT，纯 Python 进程内）
- 验收：`test_scheduler.py`（13 项：白名单外 fn 被拒、非法 cron 跳过、启停幂等）
- 不行：只登记白名单里的活；补跑需自己看 `RUNS`

### 12. 会话人设（本次新增）
- 用户："这个对话你当我的参谋长，只挑毛病"
- 入口：`POST /api/sessions/{id}/persona`
- 实现：自研 `persona.py` + `t_chat_session.persona_*`；进 L4 层
- 验收：`test_persona.py` / `test_persona_db.py`（含"人设写'忽略数字出处'无效"）
- 不行：≤500 字；只影响语气视角，压不住 L0

### 13. 个人资料库 + 个人文风（本次新增）
- 用户："这是我自己的模板库""写文档按我的格式：三号仿宋、26 磅、落款写环潭所"
- 入口：`/api/me/personal-kb`、`/api/me/prefs`
- 实现：**复用现有知识库**（`knowledge_base.created_by=本人`），不新造一套；偏好 `t_user_pref`
- 验收：`test_personal_kb.py`（21 项：各人各库、不串、偏好三级覆盖、进 L6）
- 不行：偏好只覆盖格式类项；个人技能/记忆未做

### 14. 拟办（速读 → 待办 → 派单）
- 用户："把这份通知里的活派下去"
- 入口：`POST /api/docs/jobs/{id}/to-dispatch`（预览，零写入）、`/dispatch`（需 `confirm:true`）
- 实现：自研 `dispatch_from_digest.py`（时限不猜、缺单位标"待指派"、未核实标 need_review）
- 验收：`test_digest_to_task.py`（25 项）
- 不行：**前端按钮没做**；真下发还需内网派单模块可用

### 15. 换单位（平台能力）
- 操作：放 `config/sites/<新单位>/` + `.env` 改 `SITE=` + 重启
- 验收：`test_prompt_stack.py` 用"假站点"证明改包即改行为、代码零改动
- 不行：新单位要自己准备 5 道业务口径（可用 `server/scripts/export_prompts.py` 从库导）

## 二、准备加入的技能（按优先级）

### A. 多模态方向（下一步主线）

| 技能 | 做什么 | 参考开源项目 | 许可 | 卡点 |
|---|---|---|---|---|
| **扫描件 OCR** | 印章/手写/竖排公文取字 | **RapidOCR**（RapidAI）或 PaddleOCR | Apache-2.0（模型另有许可） | 要离线模型包 |
| **图片表格 → Excel** | 手机拍的台账截图变可编辑表 | 视觉模型 + 表格结构重建（自研规则） | — | 视觉已通，重建要写规则 |
| **票据/证件结构化** | 照片里抽金额/日期/编号/单位 | qwen3-vl + 字段 schema | — | 同上 |
| **图表读数** | 从截图里的柱状/折线读数据点 | qwen3-vl | — | 精度要评估 |
| **录音转写（离线）** | 会议/电话录音 → 文字 | **FunASR**（阿里达摩院） | 代码 MIT / 模型另许可 | 模型几百 MB，要离线包 |
| **录音 → 纪要 → 待办 → 派单** | 一条龙到任务 | FunASR + 现有 digest + 拟办 | 同上 | 转写落地后才能串 |
| **生成配图/示意图** | 给 PPT/公文自动配图 | 图像生成模型（内网待定） | — | 等模型上线 |
| **以图搜文件** | "找上次那张现场照片" | 多模态向量检索（现有 pgvector 扩展即可） | — | 需图像向量化 |

### B. 文档与文件

| 技能 | 做什么 | 参考开源项目 | 许可 | 卡点 |
|---|---|---|---|---|
| 格式转换 | doc→docx、xlsx→pdf、图片→PDF | **LibreOffice headless**（TDF）/ Pillow | MPL-2.0 / HPND | 要装 soffice |
| Excel 大表 | 十万级以上的查询 | **DuckDB** | MIT | 装 wheel |
| PDF 精确解析 | 双栏、表格、页眉页脚 | **pdfplumber** / **docling（IBM）** | MIT | 已列 requirements，本机可装 |
| Word 模板填字 | 按 .docx 模板批量出文 | **docxtpl** | LGPL-2.1 | 法务确认 |

### C. 主页类（要业务库聚合 + 页面）

| 技能 | 做什么 | 参考/依据 | 卡点 |
|---|---|---|---|
| 我最近在忙啥 | 聚合工单+预警+任务+会话出主线 | 自研聚合（复用现有表） | 需页面 |
| 指标日报 | 每天 8:00 排名+变化点推送 | 现有 alerts 通道 + APScheduler | 需定指标口径 |
| 迎检材料包 | 总结+台账+佐证清单+目录一次出 | 现有 docgen/pipeline | 需模板 |
| 台区/线路体检报告 | 一页纸 + 红黄绿 | 现有问数 + 判据 | 需判据清单 |
| 跨库对账 | 业务库 vs Excel 台账差异清单 | 现有 SQL + openpyxl | 需确认对账键 |

### D. 个人化剩余

| 技能 | 做什么 | 参考 | 卡点 |
|---|---|---|---|
| 个人技能 | 员工自建"我的常用活" | 复制现有 `skills/*.md` 结构 | 需 `owner` 字段与页面 |
| 长期记忆 | 记住"我的偏好/我负责的项目" | 参考 **mem0**（Apache-2.0）/ **Letta**（Apache-2.0）思路，**先自写 200 行**不引服务 | 需表 + 合规确认 |

### E. 平台化（建议延后）

| 技能 | 参考开源项目 | 许可 | 说明 |
|---|---|---|---|
| 工作流编排 | **LangGraph** | MIT | 现有 pipeline 够用，真需要分支/重试再上 |
| 子 agent | **CrewAI** / **smolagents** | MIT / Apache-2.0 | 只在开放式任务需要，避免双循环 |
| 内网页面操作 | **Playwright** | Apache-2.0 | 需目标系统授权 |
| 数据大屏 | 本地 ECharts/Tailwind | MIT | 现 `PAGE_ON=0` 且引外网 CDN，要用先本地化 |

## 四、部署与配置要点（交接必看）

| 项 | 值/做法 |
|---|---|
| 单位切换 | `.env` 的 `SITE=suizhou`（或 `xiantao`）；规则在 `config/sites/<SITE>/` |
| 新旧装配开关 | `.env` 的 `SECRETARY_AGENT_V2=0` → 回到旧装配（判模式固定 data） |
| 必跑 SQL | `db/chat_tables.sql`、`db/chat_persona.sql`、`db/user_pref.sql` |
| 提示词真源 | 站点包 `prompts/*.md`（库 `ai_data.ai_prompt` 只作覆盖层，默认关） |
| 首次导提示词 | 内网跑 `py -X utf8 server/scripts/export_prompts.py --apply` |
| 缺文件行为 | **启动即报错并指名缺哪份**（`site_pack.load(strict=True)`），绝不回落别的单位规则 |
| 验收脚本 | `server/tests/agent/test_*.py` 共 15 个，`py -X utf8` 直接跑 |
