# 问数接口 `POST /api/ask/data`

只问数的入口。同一套预处理与查数循环，不分线、不读文件、不出文件。

## 1. 认证与地址

| 项 | 值 |
|---|---|
| 地址 | `POST http://<host>:8200/api/ask/data`（对外 80：`http://<host>/api/ask/data`） |
| 认证 | `Authorization: Bearer <JWT>`，未带 / 失效 → `401` |
| 内容类型 | `application/json`；也收 `multipart/form-data`（随附文件会被忽略，见 §6） |

## 2. 请求

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `question` | string | 是 | 用户原话。错字、简称、漏时间地点都由服务端预处理补 |
| `session_id` | string | 否 | 不传则服务端生成；多轮续问回传同一个 |
| `history_turns` | int | 否 | 读几轮上下文；`0` = 本轮不要记忆 |
| `model` | string | 否 | 缺省用配置里的模型 |
| `today` | string | 否 | 业务日期 `YYYY-MM-DD`；不传取系统当天 |
| `scope` | string | 否 | 上游强制的数据范围，只记录 |
| `profile` | string | 否 | 提问人身份 / 关注口径 |
| `kb_ids` | int[] | 否 | 知识库检索范围；不传用「参与智能问答」标记的库 |
| `stream` | bool | 否 | `true` → 立刻返回 `task_id`，之后轮询进度 |
| `channel` | string | 否 | 来源渠道，记录用 |
| `uid` | string | 否 | 业务用户标识，记录用 |

`file_ids` 与 multipart 文件**不收**：传了会被丢掉，并在响应 `doc_warnings` 里写明。

```json
{
  "question": "两水所今年预算执行率是多少",
  "session_id": "s_9f1c…",
  "today": "2026-11-12",
  "channel": "sga"
}
```

## 3. 响应

```json
{
  "answer": "两水供电所 2026 年预算执行率 46.28%，低于全市 43.81% 的口径需核实汇总表。",
  "session_id": "s_9f1c…",
  "qa_id": 10231,
  "input_question": "两水所今年预算执行率是多少",
  "fixed_question": "两水所今年预算执行率是多少",
  "completed_question": "两水所今年预算执行率是多少",
  "qtype": "查数",
  "steps": 9,
  "elapsed_ms": 18342,
  "db_query_count": 3,
  "sql_query_count": 3,
  "kb_query_count": 0,
  "no_db_query": false,
  "unverified": false,
  "trace": [ … ]
}
```

**外部集成只依赖三个字段**：`answer`（正文）、`session_id`（多轮回传）、`qa_id`（留痕主键）。

| 字段 | 类型 | 说明 |
|---|---|---|
| `answer` | string | 回答正文。模型不可用时这里是人话说明，不是异常 |
| `session_id` | string | 会话 id |
| `qa_id` | int \| null | 本次问答落库主键；`null` = 落库失败（不影响回答） |
| `input_question` | string | 原始提问 |
| `fixed_question` / `completed_question` | string | 纠错、补问法之后的问题 |
| `qtype` | string | `查数` / `分析` |
| `steps` | int | 轨迹条数 |
| `elapsed_ms` | int | 总耗时 |
| `db_query_count` / `sql_query_count` / `kb_query_count` | int | 各类工具调用次数 |
| `no_db_query` | bool | 本轮有没有查业务库 |
| `unverified` | bool | 证据不足被拦；`true` 表示「没查到」，不是故障 |
| `artifacts` | array | 恒为空（此接口不出文件） |
| `doc_warnings` | string[] | 仅当请求带了文件时出现 |
| `trace` | array | 轨迹，排障用，见 §4 |
| `page_html` / `page_token` | string | 分析页面（配置关了则为空串） |

`Decimal` 一律转成字符串返回。

## 4. 轨迹 `trace[]`

每条一个对象，`kind` 标记这是第几步。

| `kind` | 含义 |
|---|---|
| `route` | 固定为 `{"lane":"ask_db","why":"本接口只问数，不分线","forced":true}` |
| `intent` | `use_db=true`、`use_file=false`、`make_file=false` |
| `namefix` | 字面纠错与名称归一（`word_fixes` / `name_fixes` / `names` / `areas`） |
| `complete` | 补问法（只在原话没说清问什么时出现） |
| `confirm` | 问题确定 |
| `rules` / `system` / `tools` | 规则目录条数、system 提示词字数、本轮给了哪几只工具 |
| `tool` | 一次工具调用：`tool` / `args` / `ms` / `round` / `result` |
| `progress` / `evidence` / `verify` / `final` | 进度事实、证据、核对、收尾 |
| `answer` | 最终正文（`content` 为前 600 字） |

可用的工具固定六只：`kb_search` `list_metrics` `metric_query` `run_sql` `read_result` `finish`。

## 5. 流式

`{"stream": true}` → 立刻返回：

```json
{"task_id": "t_cd09a7f53e68", "stream": true, "session_id": "s_9f1c…"}
```

| 接口 | 用途 |
|---|---|
| `GET /api/ask/progress?task_id=` | 边跑边读；`done=true` 时带完整结果 |
| `POST /api/ask/stop?task_id=` | 停止生成，回答收成「（已停止生成）」 |

## 6. 与 `POST /api/ask` 的差别

| 项 | `/api/ask` | `/api/ask/data` |
|---|---|---|
| 入口分线 | 判 office / read / ask_db / chat | 不分线，恒 `ask_db` |
| 查库 / 读文件 / 出文件 | 按本轮原话判 | 固定 是 / 否 / 否 |
| 可用的工具 | 按判据给子集 | 只有查数六只 |
| 预处理 | 只在 `ask_db` 线上跑 | 照跑：纠错 → 补问法 → 问题确定 |
| 产物（docx / xlsx / pptx） | 有 | 无 |
| 拟办任务草稿 `task_draft` | 有 | 无 |
| 大屏跳转字段 `layer` / `method` / `mainId` / `data` | `want_screen=true` 时可能有 | 同左（同一套转发，契约见《大屏跳转对接说明》§三） |
| 随附文件 | 读取并作事实来源 | 忽略，`doc_warnings` 说明 |

跳大屏就带 `want_screen: true`；不配 `SCREEN_PREVIEW_URL` 或对方没识别，这四个字段不出现，前端不跳转。

## 7. 错误码

| 情形 | 返回 |
|---|---|
| 未带 / 令牌无效 | `401` |
| `question` 为空 | `200 {"answer":"问题为空","trace":[]}` |
| 所选知识库全部不可用 | `403 {"answer":"所选知识库不可用（不存在、已停用或没有权限）","trace":[],"session_id":"…"}` |
| `task_id` 不存在 / 超 30 分钟 | `404 {"error":"任务不存在或已过期"}` |
| 模型网关没有该模型 / 连不上 | `200`，`answer` 是人话说明，同时落库留痕 |

## 8. 调用示例

```bash
curl -X POST http://127.0.0.1:8200/api/ask/data \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"question":"全市预算总额是多少","channel":"api"}'
```

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8200/api/ask/data -Method Post `
  -Headers @{ Authorization = "Bearer $TOKEN" } `
  -ContentType 'application/json; charset=utf-8' `
  -Body ([Text.Encoding]::UTF8.GetBytes('{"question":"全市预算总额是多少","channel":"api"}'))
```

## 9. 实测

模型 `deepseek-v4.1-flash`，业务库线上只读，记录库 PG。同一句「帮我写个 word 通知，说清楚全市预算总额和执行率」：

| 入口 | `lane` | 工具 | 产物 |
|---|---|---|---|
| `/api/ask/data` | `ask_db`（`forced:true`） | 查数六只 | 无 |
| `/api/ask` | `office` | 全套 | docx 38,852 B，自检通过 |

判据 16 项全过（`server/tests/agent/test_ask_data_lane.py`）。
