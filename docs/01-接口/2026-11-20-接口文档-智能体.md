## 1 跑一轮：`POST /api/agent/run`

**① 概述**

| 项 | 值 |
|---|---|
| 方法/路径 | `POST /api/agent/run` |
| 鉴权 | `Authorization: Bearer <access_token>` |
| 请求 Content-Type | `application/json` |
| 响应 Content-Type | `text/event-stream`；响应头另含 `Cache-Control: no-cache`、`X-Accel-Buffering: no` |
| 流格式 | 每个事件 = `event: <type>` 一行 + `data: <单行 JSON>` 一行 + 空行；`event:` 行与 `data.type` 恒相同 |

**② 请求参数（JSON body）**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `text` | string | 是 | 交代的事；`strip()` 后为空 → `400 EMPTY` |
| `session_id` | string \| null | 否 | 省略 = 新建会话；UUID = 沿用该会话；非 UUID 老 id（如 `s_xxx`）= 走 `qa.agent_alias` 映射，无映射则新建并回写映射 |
| `file_ids` | string[] | 否 | 本轮附件。服务端把 `- 《文件名》 file_id=…` 拼到输入末尾，正文由模型调 `read_file` 取；取不到的文件写 `file_id=…（取不到名字）` |

**③ 响应字段（SSE 事件）**

| 事件（`event:` 行 = `data.type`） | 字段 | 类型 | 说明 |
|---|---|---|---|
| `run` | `run_id` | string | 本轮 id，`POST /api/agent/stop` 与 spans 用它 |
| | `session_id` | string | 会话 UUID；新建会话时由服务端生成，前端据此落侧栏 |
| | `model` | string | 本轮模型名 |
| `text-delta` | `text` | string | 正文增量片段；多事件按序拼接；已过工具语法过滤（`<tool_use>…</tool_use>` 段整段丢弃） |
| `tool-call-start` | `tool_call_id` | string | 工具调用唯一 id，后两类事件靠它配对 |
| | `name` | string | 工具名（`read_file` / `make_file` / `read_skill` / `list_skills` / `search_kb` / `query_data` / `db_schema` / `remember` / `recall`） |
| `tool-call-args-delta` | `tool_call_id` | string | 同上，配对用 |
| | `text` | string | 参数 JSON 文本，单事件截到 2000 字符 |
| `tool-call-result` | `tool_call_id` | string | 同上，配对用 |
| | `result` | string | 工具输出原文，截到 4000 字符 |
| | `is_error` | bool | 输出以「工具执行失败」开头即 `true` |
| `file` | `name` | string | 文件名 |
| | `file_id` | string | 文件 id |
| | `url` | string | 下载地址 `/api/files/{file_id}/download` |
| | `kind` | string | `docx` / `xlsx` / `pptx` |
| | `size` | int | 字节数（取 `make_file` 结果的 `bytes`，缺失为 `0`） |
| `error` | `message` | string | 流内异常文本 `异常类名: 内容`（≤300 字符）。**未实测**：实查两轮均未触发 |
| `finish` | `run_id` | string | 本轮 id |
| | `session_id` | string | 会话 UUID |
| | `status` | string | `done` / `stopped` / `failed` |
| | `answer` | string | 终稿全文（同样过滤过工具语法） |
| | `artifacts` | array | 本轮产出的文件，元素字段同 `file` 事件（`name/file_id/url/kind/size`）；无文件为 `[]` |
| | `usage.tokens` | int | 本轮总 token |
| | `error` | string | 失败原因，成功为空串 |
| | `ms` | int | 本轮耗时（毫秒） |

`file` 事件是「文件即出即推」：`make_file` 的工具结果一到就发，不再等整轮结束（旧实现在结尾补发 `artifact`，该类事件已删）。

本批提交（`e13996c`）改掉的事件契约（`95fe201` 及之前的旧名）：

| 旧事件名 | 现状 |
|---|---|
| `delta` | 改名 `text-delta` |
| `tool_call` | 拆成 `tool-call-start`（`tool_call_id`+`name`）与 `tool-call-args-delta`（`tool_call_id`+`text`） |
| `tool_result` | 改名 `tool-call-result`；字段 `brief` 改为 `result`+`is_error`，`ms` 移出事件（改为 spans 里的 `ms`） |
| `message` | 删除，正文只走 `text-delta` |
| `artifact` | 删除，改由 `file` 即时推送 |
| `done` | 改名 `finish`；`tokens` 收进 `usage.tokens`，新增 `error` |

**④ 错误码**

| 状态码 | `detail.code` | `detail.message` | 触发 |
|---|---|---|---|
| 400 | `EMPTY` | `说点什么` | `text` 去空白后为空（实测） |
| 401 | `NOT_AUTHENTICATED` | `缺少访问凭证` | 请求头无 `Authorization`（实测） |
| 401 | `INVALID_TOKEN` | `登录凭证无效或已过期` | 令牌非法/过期（实测于同鉴权依赖的 `/api/agent/config`） |
| 422 | `VALIDATION_ERROR` | `请求参数校验失败` | 请求体不是合法 JSON（实测） |

HTTP 状态码始终 `200`，流内异常不改状态码：走 `error` 事件 + `finish.status=failed`。

## 2 停止一轮：`POST /api/agent/stop`

**① 概述**

| 项 | 值 |
|---|---|
| 方法/路径 | `POST /api/agent/stop` |
| 鉴权 | `Authorization: Bearer <access_token>` |
| Content-Type | 请求/响应均 `application/json` |

**② 请求参数（JSON body）**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `run_id` | string | 是 | 要停的那一轮；取自 `run` 事件或 `finish` 事件的 `run_id` |

**③ 响应字段**

| 字段 | 类型 | 说明 |
|---|---|---|
| `ok` | bool | 恒 `true` |

`run_id` 不校验是否存在，也不校验归属：不存在 / 已结束 / 别人的 run 一律 `{"ok":true}`（实测：已结束的 run 与随机 UUID 都是 `200 {"ok":true}`）。停止生效于下一次事件循环检查，被停轮次的 `finish.status` 为 `stopped`。

**④ 错误码**

| 状态码 | `detail.code` | 说明 |
|---|---|---|
| 401 | `NOT_AUTHENTICATED` / `INVALID_TOKEN` | 未登录 / 令牌失效 |
| 422 | `VALIDATION_ERROR` | 缺 `run_id` 或不是字符串（按代码，未实测） |

**⑤ 实查示例**

```json
{"run_id": "dea47087-645c-45bf-8add-6b74d3119e89"}
```

```json
{"ok":true}
```

## 7 附件与文件（`/api/files`）

### 7.1 上传附件：`POST /api/files`

**① 概述**

| 项 | 值 |
|---|---|
| 方法/路径 | `POST /api/files` |
| 鉴权 | `Authorization: Bearer <access_token>` |
| Content-Type | 请求 `multipart/form-data`；响应 `application/json` |

**② 请求参数（multipart）**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `file` | binary | 是 | 原件；上限 `settings.max_upload_mb` MB，空文件拒收 |
| `purpose` | string | 否 | `chat`（默认）/ `task` |

**③ 响应字段**（上传即解析；解析失败也回 `file_id`，`parsed.ok=false` + `error`）

| 字段 | 类型 | 说明 |
|---|---|---|
| `file_id` | string | 文件 id，`POST /api/agent/run` 的 `file_ids` 用它 |
| `name` | string | 文件名 |
| `ext` | string | 扩展名（带点） |
| `size` | int | 字节数 |
| `sha256` | string | 内容摘要（同内容重复上传复用同一记录） |
| `purpose` | string | 上传时给的用途 |
| `created_at` | string | ISO8601 带时区 |
| `parsed.ok` | bool | 是否解析成功 |
| `parsed.chars` | int | 正文字符数 |
| `parsed.blocks` | int | 段落块数 |
| `parsed.headings` | int | 标题数 |
| `parsed.tables` | int | 表格数 |
| `parsed.preview` | string | 正文前段预览 |
| `parsed.warnings` | array | 解析告警 |
| `parsed.meta` | object | 解析元信息 |

| 状态码 | `detail.code` | `detail.message` | 触发 |

| 400 | `EMPTY_FILE` | `文件是空的` | 上传 0 字节（实测） |

### 7.3 下载原件：`GET /api/files/{file_id}/download`

**① 概述**

| 项 | 值 |
|---|---|
| 方法/路径 | `GET /api/files/{file_id}/download` |
| 鉴权 | `Authorization: Bearer <access_token>` |
| Content-Type | 响应按扩展名给定（`docx` = `application/vnd.openxmlformats-officedocument.wordprocessingml.document`），另带 `Content-Disposition: attachment; filename*=utf-8''<百分号编码文件名>` |

此地址就是 `file` 事件 / `finish.artifacts[]` 里的 `url`，也是附件卡片的 `href`。

**② 请求参数**

| 位置 | 名称 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| path | `file_id` | string | 是 | 文件 id |
| header | `Authorization` | string | 是 | 不带 → 401（同其余接口的鉴权依赖） |

**③ 响应字段**

| 项 | 说明 |
|---|---|
| 响应体 | 原件二进制 |
| `Content-Type` | 按扩展名 |
| `Content-Disposition` | `attachment; filename*=utf-8''<百分号编码文件名>` |
| `Content-Length` | 字节数 |

**④ 错误码**

| 状态码 | `detail.code` | `detail.message` | 触发 |
|---|---|---|---|
| 404 | `FILE_NOT_FOUND` | `文件不存在或不属于当前用户` | id 不存在或非本人（实测） |
| 401 | `NOT_AUTHENTICATED` / `INVALID_TOKEN` | — | 未登录 / 令牌失效 |

## 8 前端调用点

| 接口 | `web/src/...` 文件与函数 |
|---|---|
| `POST /api/agent/run` | `web/src/components/agent/useAgent.ts` → `useAgent().send()`（`fetch` 直连 + `res.body.getReader()` 逐块解析 `data: ` 行） |
| `POST /api/agent/stop` | `web/src/components/agent/useAgent.ts` → `useAgent().stop()` |

| `GET /api/agent/sessions/{sid}` | 无调用点（前端未用） |

| `GET /api/agent/runs` | `web/src/pages/AgentChat.tsx` → `ChatPane.openSession()`（用首条 run 的 `id` 挂观测右栏） |
| `GET /api/agent/runs/{run_id}/spans` | `web/src/components/agent/TraceRail.tsx` → `load()`（1.5 s 轮询，最多 40 次） |
| `GET /api/agent/config` | `web/src/components/agent/AgentConfigPanel.tsx` → `load()`；`web/src/pages/AgentChat.tsx` → 首屏读 `model.name` |
| `PUT /api/agent/config` | `web/src/components/agent/AgentConfigPanel.tsx` → `save('style'\|'tools'\|'skills')` |
| `GET /api/agent/overview` | `web/src/pages/Overview.tsx` → `load()`（首页 `/home`） |
| `POST /api/files` | `web/src/components/agent/Composer.tsx` → `pick()`（`FormData` + `purpose=chat`） |

| `GET /api/files/{file_id}/download` | `web/src/components/agent/MessageView.tsx` → `FileCard` 的 `href={f.url}`（`url` 取自 `file` 事件；`<a>` 直开不带 `Authorization` 头） |
