## 4. 不兼容点（前端要改的）

1. `steps` 在 `GET /api/history` 里：`with_steps=false` 是整数，`true` 是数组，用户消息是 `null` —— 不能写成数组类型。
2. `GET /api/v1/site/config` 的 `mysql.db_port` 是数字；`GET /api/internal/status` 的 `business_db.port` 是字符串。
3. 现场未就绪时所有业务接口回 503 + `detail.code=SITE_NOT_CONFIGURED`，不是 401，不要跳登录。
4. 切现场后旧 token 401（`sid` 校验），需重新登录。
5. `site/test` 的失败也是 `200` + `ok:false`；`PUT site/config` 连不上产品库同样 `200` + `ok:false`。
