## 0. 通用约定

| 项 | 值 |
|---|---|
| 路径前缀 | `/api/v1/runtime` |
| 鉴权 | `Authorization: Bearer <access_token>`（无角色限制，任何登录用户可用） |
| Content-Type | `application/json` |
| 错误体 | 本域**不用**统一错误体：失败回 `{"error":"…"}`（见各接口） |
| 生效方式 | 保存即生效，无需重启；`values` 是页面上存的值，`defaults` 是代码/环境里实际生效的值 |

配置键（`runtime_cfg.KEYS`）：

| 键 | 含义 |
|---|---|
| `model` | 问数用的模型 |
| `model_channel` | 模型通道（`local` / `online`） |
| `llm_base_url` | 模型网关地址（OpenAI 兼容 base_url） |
| `llm_api_key` | 模型网关 API Key |
| `llm_model` | 模型名 |
| `max_steps` | 单题最多几轮工具调用 |
| `db_host` / `db_port` / `db_name` / `db_user` / `db_password` | 业务库连接（只读账号） |
| `sql_timeout_ms` | 单条 SQL 超时（毫秒） |
| `tool_result_chars` | 单次工具结果给模型的字数上限 |

## 1. 读运行配置 `GET /api/v1/runtime/config`

| 项 | 值 |
|---|---|
| 方法/路径 | `GET /api/v1/runtime/config` |
| 鉴权 | Bearer JWT |
| Content-Type | `application/json` |

请求参数：无。

响应字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `ok` | bool | 恒 `true` |

## 2. 保存运行配置 `PUT /api/v1/runtime/config`

| 项 | 值 |
|---|---|
| 方法/路径 | `PUT /api/v1/runtime/config` |
| 鉴权 | Bearer JWT |
| Content-Type | `application/json` |

请求体：上表配置键的任意子集，值为字符串（数字也按字符串存）。**空串＝恢复代码默认**；未提交的键不改。

响应字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `ok` | bool | 是否保存成功 |
| `saved` | int | 本次写入的键数 |
| `values` | object | 保存后页面上的全量值（同 GET） |

实测（把当前 11 个键原样写回）：

```json
{
  "ok": true,
  "saved": 11,
  "values": {
    "tool_result_chars": "12000",
    "max_steps": "100",
    "db_host": "47.121.183.81",
    "db_port": "3306",
    "db_name": "ai_data",
    "db_user": "root",
    "db_password": "<脱敏>",
    "model_channel": "online",
    "llm_base_url": "https://llm-dk4h22odcm9j1oqk.cn-beijing.maas.aliyuncs.com/compatible-mode/v1",
    "llm_api_key": "<脱敏>",
    "llm_model": "deepseek-v4.1-flash"
  }
}
```

错误码：

| 状态码 | 响应体 | 触发条件 |
|---|---|---|
| 400 | `{"error":"请求体不是 JSON"}` | 请求体不是 JSON |
| 400 | `{"error":"请求体必须是 JSON 对象"}` | 请求体是数组/标量 |
| 500 | `{"ok":false,...}` | 写库失败 |

```json
{ "error": "请求体不是 JSON" }
```

## 3. 试连业务库 `POST /api/v1/runtime/test`

| 项 | 值 |
|---|---|
| 方法/路径 | `POST /api/v1/runtime/test` |
| 鉴权 | Bearer JWT |
| Content-Type | `application/json` |

请求体：可选的 `db_host` / `db_port` / `db_name` / `db_user` / `db_password`；不传或空对象＝用当前生效连接。只试连，不保存。

响应字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `ok` | bool | 能否连上 |
| `result` | object | 成功时是 `select 1` 的结果，如 `{"ok": 1}` |
| `host` / `db` | string | 成功时回显连的地址与库名 |
| `error` | string | 失败原因，如 `OperationalError: (2003, …)` |

实测（当前生效连接）：

```json
{ "ok": true, "result": { "ok": 1 }, "host": "47.121.183.81", "db": "ai_data" }
```

实测（连不通的地址）：

```json
{
  "ok": false,
  "error": "OperationalError: (2003, \"Can't connect to MySQL server on '127.0.0.1' ([WinError 10061] 由于目标计算机积极拒绝，无法连接。)\")"
}
```

错误码：`401 NOT_AUTHENTICATED`、`503 SITE_NOT_CONFIGURED`（体同上）。
