# 回答职责划分 + 结果性文字 + 通用能力（2026-10-19）

## 目的

Fred 反馈：回答冗余、答非所问（问原因却答怎么解决）、罗列数据让领导自己判断、把一切都当业务查库问题。
根因不是模型不听话，是**三套规范方向相反**，写全才不违规。本计划只做删改与职责划分，不加新规则。

## 三处职责（改完后的分工）

| 位置 | 管什么 | 验证方式 |
|---|---|---|
| `ai_prompt.answer_agent`（线上库，注入 system） | 人格与边界：小智的身份、口吻、什么情况不查库、非业务直接答 | 查库读出正文，逐条对 |
| `server/app/secretary/skills/判据规则.md` | 事实与口径：字段/状态码/阈值/多口径区分/问法归一/比较基准 | 抽查 3 段，确认无"写几段/多长/必须给建议" |
| `server/app/secretary/agent.py` 常量 | 回答纪律（全系统唯一一份）：分层、长度、结论先行、禁过程话术 | 读常量，确认无冲突条款 |

## 验收判据（先定死）

单问 6 题 + 连续问答 1 场（4 轮），每题记录问题、回答、耗时、trace 步数。

| # | 题 | 判据 |
|---|---|---|
| S1 | 环潭这次分了多少？ | ≤3 行，只给数+口径，不出现"建议/下一步/成效" |
| S2 | 全市哪个所已审批金额最多？ | 第一句直接给"哪个所+多少"，不列全表 |
| S3 | 唐镇今年分了多少、花了多少、还剩多少？ | 逐问给数，不加推算/下一步 |
| S4 | 唐镇今年的预算情况怎么样？ | 按预算标准项给全 + 一句结论，不跨到建议 |
| S5 | 为什么环潭分得比唐镇多？ | 只讲成因与证据，不出现动作段 |
| S6 | 明年想让环潭多拿预算，该干什么？ | 必须给动作（对象+量+指标） |
| S7 | 你好，你能干什么？ | 不调工具、不套业务话术、无"未核实/未调用工具"字样 |
| C1-C4 | 一场：某所预算 → "为什么" → "那怎么办" → "换个所呢" | 只答被问层；追问继承对象；口径不漂 |

每题重跑 3 次，3/3 达标才算过（提示词是概率，实测同条规则 9/11）。
