# 分析问题拆解 · 08「哪些项目钱花了没动？」

## 一、谁问、问谁
所长 / 县领导 / 市领导；对象：本所 / 全县 / 全市。

## 二、想要什么答案
**逐条清单 + 卡了多久 + 该谁动**，且要说清"钱花了"是按什么算的（实际投入还是预算口径）。

## 三、思维链
1. **先定"钱花了"的口径**：优先查 **`t_power_work_cost`**（有 `reality_total_price` 实际金额）——**先测有值率**；有值率低就说明只能用预算金额代替，且必须写明。
2. **再定"没动"**：状态停在「审核通过待施工 / 施工中」超过 90 天；停留用 `t_power_work_order_status`（不是创建时间）。
3. **筛出来**：金额排本所前若干位 + 满足 2 的条件。
4. **排序**：按金额或停留天数（说明用的哪个）。
5. **定责**：用状态流转的 `node_type` 判断卡在哪个环节 → 对应角色。
6. **结论 + 建议**：先推哪几个、谁去推。

## 四、回答要出现什么
结论（几条、多少钱、卡在哪个环节）→ 逐条（项目名/所/状态/金额/停留/卡在谁）→ 建议。

## 五、数据可得性 / 坑
- `t_power_work_cost` 12385 行、有 `reality_quantity/reality_total_price`——**但按工单覆盖多少还没测**，测完才能定口径
- 别用"创建时间"当停留起点
- 空集就写"按该口径无记录并说明口径"，不要为了凑数放宽条件
