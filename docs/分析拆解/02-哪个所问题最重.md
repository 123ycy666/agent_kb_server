# 分析问题拆解 · 02「哪个所问题最重？」

> 格式同 01：谁问 → 想要什么答案 → 思维链 → 回答要出现什么 → 数据可得性 → 坑。

## 一、谁在问、问的是谁

- 角色：市公司领导（也可能是县公司领导问本县）
- 对象：全市（或本县公司下各所）
- 场合：要挑重点治理对象、要定下阶段资源往哪倾斜
- 原话大概是：「哪个所问题最重」「哪个所最差」「先治谁」

## 二、想要什么答案（一句话）

**不是一个"最差的所名"，而是：是谁 + 重在哪几项 + 比第二名差多少 + 建议先抓什么。**
而且"重"**不能只看金额** —— 要看指标、看项目推进、看钱用得怎么样。

## 三、思维链

**第 1 步 · 先定义"重"由哪几类构成（不定义就会只看金额）**
- ① **问题指标重**：六项里"问题导向"的那几项（线损、停电时长、跳闸、报修、意见工单、低电压）
- ② **项目推进慢**：在办项目多但卡着不动 / 停留久 / 钱花了没动
- ③ **钱用得差**：执行率低、余额躺着、该批没批
- ④ **合规问题多**：重复申报、金额离群、明细不平（作为附加标记，不参与主排序也可以）

**第 2 步 · 逐个维度算，每个维度都要能说出"这个所在这一项上排第几"**
- 指标：`t_power_ai_metric_snapshot`（scope_type=station、period_type=yearToDate、最新期次；**注意 `source_summary_type` 不钉住会读出两个差好几倍的值**）+ `t_power_ai_metric_comparison`（同比，缺则退年度）
- 指标方向：`better_direction` 区分"越大越好 / 越小越好"（跳闸、停电时长是越小越好；售电量是越大越好）
- 推进：`t_power_work_order`（状态分布）+ **`t_power_work_order_status`**（每个所卡在哪个节点、停留多少天）
- 钱：`t_power_company_budget_result` + 状态 3/6/7 的工单 → 执行率
- 画像（辅助）：`t_power_company_budget_profile`（线路/台区/用户规模 —— **规模大本身不是问题**，但要比"单位规模下的问题"）

**第 3 步 · 归一化后再合**
- 指标量纲不同（线损是 %、停电是小时、跳闸是次）→ **先各自排名或算相对全市的偏离度**，再合成
- 不能简单把"条数"和"率"相加；至少要说清**用的是排名法还是偏离度法**
- 得出：**排前几名的所 + 每个所"重在哪几项"**

**第 4 步 · 验证（不做这步就会给出自己都说不清的结论）**
- 把第一名的每个维度值拉出来，跟第二名、跟全市均值并排看：**它到底是不是真的重**
- 检查有没有被"规模/口径"带偏：某个所跳闸次数多，可能只是线路长、台区多 → 要看**单位长度的跳闸数**这类相对值

**第 5 步 · 说清"建议先抓什么"**
- 第一名的短板项 → 对应到它能做什么（高损台区改造 / 频繁跳闸线路 / 低电压台区）
- 用 `t_power_area` / `t_power_line` 找到具体对象，说明"先抓哪个台区/线路"

## 四、回答要出现什么（回答模板由提示词控制）

1. **结论**：问题最重的是哪个所（一句话）
2. **重在哪几项**：逐项给"它的值 / 全市值 / 排第几"（这就是**依据**）
3. **量化差距**：跟全市／其他所差多少（倍数或百分点），并说明与第二名的关系（拉开还是咬紧）—— 说明不是随意挑的
4. **建议先抓什么**：哪个方向、从哪些对象入手

## 五、数据可得性

| 要用的数 | 在哪 | 状态 |
|---|---|---|
| 六项指标（所级） | t_power_ai_metric_snapshot（station + yearToDate） | ✅ 需钉 source_summary_type |
| 同比 | t_power_ai_metric_comparison | ⚠️ 当期档常空 → 退年度 |
| 指标方向 | 该表的 better_direction | ✅ |
| 卡点与停留 | **t_power_work_order_status** | ✅ 有节点名+时间 |
| 执行率 | budget_result + work_order(3/6/7) | ✅ |
| 规模画像 | t_power_company_budget_profile | ✅ 46 行（所×年） |

## 六、坑

1. **只看金额 = 没答**（这是我以前犯的）。
2. **规模大的所问题不一定重** → 关键项要用相对值。
3. 量纲不同不能直接相加 → 先排名/偏离度。
4. 指标快照同一期次可能有两组值（当前月 / 累计），必须钉死用哪一组。
5. 别把"审核中数量多"当成"问题重"——那可能只是流程正常。
