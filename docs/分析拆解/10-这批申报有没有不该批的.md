# 分析问题拆解 · 10「这批申报里有没有不该批的？」

## 一、谁问、问谁
市 / 县公司领导、财务部；对象：全市 / 本县当年在办或新提交的申报。

## 二、想要什么答案
**分类计数 + 逐条依据，不许抽样**：多少条不符合、卡在六条里的哪几条各几条、前几条明细、谁去核实。

## 三、思维链
1. **定扫描范围**：当年创建的、状态在办（1/2）或已通过（3/6/7）的工单；**说明扫了哪些、没扫哪些**。
2. **逐单过六条**：有工单载体 / 预算装得下（当年可用余额 ≥ 申报额）/ 类型匹配 / 明细完整（工程费+物资费=总额，用精确到元的原值，差额>1% 才算）/ 工期合理 / 金额可比（同类分布）。
3. **分类计数**：按"卡在哪一条"分组 → 各几条。
4. **逐条列前 N 条**（条数多就列前 20 + 余下合计）。
5. **定责**：不同类型的问题对应谁处理（财务 / 运检 / 所长）。
6. **结论**：整体合规情况 + 最集中的问题类型。

## 四、回答要出现什么
结论（扫了多少、几条不符合）→ 分类计数 → 逐条依据 → 建议谁核实。

## 五、数据可得性 / 坑
- **必须全量扫**：只挑一个所/一张单当样本 = 没答
- 结论只有"符合 / 不符合 / 无法判定"三种，**必须与依据一致**（依据写"对得上"就不能标不符合）
- "已批过"的单不重判"装不装得下"（它的钱已经在已审批里，再比剩余余额会重复扣）
- 编号一律翻中文；工期字段大量为空 → 标"无法判定"并说明是数据缺失，不是项目不合格
