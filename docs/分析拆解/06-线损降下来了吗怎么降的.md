# 分析问题拆解 · 06「线损降下来了吗？怎么降下来的？」

## 一、谁问、问谁
县公司领导 / 所长；对象：本县或本所。场合：成效评估、被上级问指标为什么没动。

## 二、想要什么答案
**趋势 + 归因**：降没降、降了是靠什么降的、还有哪些没治、还能怎么降。
不是报一个"线损率 2.61%"。

## 三、思维链
1. **先分口径**：线损有**台区线损率**和 **10kV 线损率**两个口径（缺陷类型里 2/19=台区线损、12=10kV线损）。问"线损"要先确认或分别说明，不能混。
2. **取多期趋势**：`t_power_ai_metric_snapshot` 同一 scope 的 **多个期次**（年度 2024/2025/2026 + 累计），拼成时间序列 —— 单期看不出"降下来"。
3. **横向对照**：全市 / 同类所同期值 → 是普遍趋势还是这个所特有。
4. **查投入**：`t_power_work_order` 按 `defect_type` 分组、分年度，看这个所在线损方向上**往年投了多少、投了几个项目**。
5. **做时间对齐（归因的核心）**：投入在前、指标变化在后才可能是因果关系；**同一时期投入了但指标没动 → 投法或方向有问题**；没投也没降 → 可能是别的原因（如负荷变化），没依据就不下因果结论。
6. **找还没治的**：`t_power_area` 里高损台区、`t_power_company_budget_profile` 的 `station_line_loss` 画像 → 还有哪些台区没动过。
7. **结论 + 建议**：降了/没降、靠什么、下一步该治哪些台区。

## 四、回答要出现什么
1. 结论：降了还是没降、跟去年比差多少
2. 依据：多期数值 + 全市值 + 排名
3. 归因：往年投入了多少、投完有没有变化（**带"根据以往数据"**）
4. 还剩哪些没治
5. 建议

## 五、数据可得性 / 坑
- `t_power_push_line_loss` **是空的**，线损只能走快照表
- 同一期次可能两组值（当前月 / 累计）→ 必须钉 `source_summary_type`
- 投入见效有时间滞后，别拿"今年投的"对"今年降的"直接下结论
