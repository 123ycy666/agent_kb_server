# 分析问题拆解 · 11「X 所今年整体怎么样？」

## 一、谁问、问谁
市领导 / 县领导问一个所（也可能行长、上级调研时问）。这是**最常问、最考水平**的一题。

## 二、想要什么答案
**一句话结论 + 三个最关键的问题 + 该先抓什么**。
**不是四个视角平铺**——领导要的是"这个所有什么问题、严重不严重、先干什么"。

## 三、思维链
1. **钱**：分配 / 已审批 / 执行率 / 余额；跟时间进度比（快慢）；卡在哪一环。
2. **项目**：今年几条、状态分布、卡点在哪、有没有钱花了没动、年内完不成。
3. **指标**：六项本期 vs 全市 vs 同期，找出明显偏差的。
4. **合规**（可选）：有没有离群、重复申报这类硬伤。
5. **收敛（这一步决定回答好不好）**：从上面挑出**最突出的 2~3 个问题**，每个都要有数据支撑（值是多少、排第几、跟去年比）。
   —— **平铺 = 没答**；领导读不出重点。
6. **建议**：先抓哪个、从哪些对象入手、预计效果。

## 四、回答要出现什么
1. 一句话结论（这个所今年怎么样）
2. 三个关键问题（各带一个数据）
3. 建议先抓什么

## 五、数据可得性 / 坑
- 数据分散在：budget_result / work_order / work_order_status / metric_snapshot / metric_comparison / budget_profile
- **不要四视角平均用力**；宁可少说一件，也不要列成流水账
- 多轮追问（为什么 / 怎么办）时要承接这一轮的对象，不许换对象
