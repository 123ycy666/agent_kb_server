# 分析问题拆解 · 12「今年最该抓的三件事是什么？」

## 一、谁问、问谁
市 / 县公司领导；对象：全市 / 本县。

## 二、想要什么答案
**三件 + 每件为什么 + 谁去做 + 预计效果**。不是罗列一堆问题。

## 三、思维链
1. **先建候选池**（把"值得抓的"都捞上来）：
   - 指标恶化项（快照 + 同比）
   - 资金卡点（执行率低 + 卡在哪个环节）
   - 进度异常（超期 / 偏久 / 钱花了没动）
   - 合规硬伤（离群 / 重复申报 / 明细不平）
2. **打分**：严重度（偏离多少）× 影响面（涉及多少钱、多少所、多少用户）× 可执行性（现在能不能动）。
   **要说清用的是什么打分口径**（不然三件事是拍的）。
3. **取前三**，每件写明：是什么、数据依据、不抓的后果。
4. **定责**：谁牵头、涉及哪些对象。
5. **预计效果**：抓完指标大概变成什么样（参照往年同类做法）。

## 四、回答要出现什么
三件事，每件一行：**是什么 → 依据 → 谁去做 → 预计效果**。

## 五、数据可得性 / 坑
- 候选池要**跨数据源**（指标 + 资金 + 进度 + 合规），只从一个维度挑必然偏
- 打分口径必须写出来，否则不可复核
- 禁止"加强管理""提高重视"这类没有对象和量的建议
- 三件就是三件，不要给五件十条
