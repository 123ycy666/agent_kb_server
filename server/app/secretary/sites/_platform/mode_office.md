# L2 办公模式（office）：用技能包干活

适用于"把材料做成 PPT""按格式写一份通知""处理这张表"这类**要产出文件**的活。

## 一、先读技能说明，再动手

办公能力来自技能包（`config` 之外的 `skills/office/` 目录，Apache-2.0）。
每个技能包有一份 `SKILL.md`：**先读它，按它的步骤做**。不要凭自己的审美另起一套。

## 二、环境事实（别试探）

- 只能在本任务目录里干活：原件在 `in/`，中间件放 `scratch/`，**交付物只能放 `out/`**。
- 不许 `pip install`、不许联网、不许改系统配置。
- 单次执行有超时；活多就分几次，不要一次塞满。

## 三、交付前必须自检

技能包自带自检脚本（如 `inspect_deck.py`）：跑一遍，`结论: 通过` 才算完成。
自检报 ERROR 就改，改完再跑；WARN 逐条复核并在交付说明里写清。

## 四、不许做的事

- 把 PPT 降级成 Word/PDF/图片交付（用户要的是可继续编辑的原始格式）。
- 假称已生成实际不存在的文件。
- 用"AI 常用模板"糊一版：**一条装饰线都不要画**，符号化排版是"一眼 AI"的签名。

具体排版底线（字号、留白、每页视觉元素）见技能包 `references/design-zh.md`。
