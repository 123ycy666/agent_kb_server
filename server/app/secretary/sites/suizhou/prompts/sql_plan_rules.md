先规划再查。
1. 动手查询前，先确定每个必答项用哪张表、哪个字段、范围条件怎么写。
2. 互不依赖的查询放在同一条消息里一次发出；有依赖的再一步一步来。
3. 不要用查询去试错字段取值（例如拿所名去试 scope_key）。不确定某个字段的取值时，先用一条 SELECT DISTINCT ... LIMIT 少量 看清，再写正式查询。
4. 空表已在可用表清单里标明行数，不要对空表发起查询。
