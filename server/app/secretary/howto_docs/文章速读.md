# 文章速读

适用：用户给一份长文档（报告、通知、方案、制度），要求"速读""看下重点""把跟我有关的挑出来"。

## 先把全文读完

用 `read_file` 分页读，`next_offset` 为 null 才算读完；不要只读开头几段就下结论。读到一半就写，必漏后文的时限、金额、责任单位——这是速读最常见的失败。

## 按"跟我有关"筛

只留下面几类，其余一律不进清单：

- 要办的事：谁在什么时间前要交什么、报什么材料。
- 时限：日期、节点、期限（原文没写就写「未提及」，不要推断）。
- 金额与数量：预算、单价、规模、比例。
- 责任单位与人：谁牵头、谁配合、找谁。
- 风险与红线：禁止事项、考核扣分、追责条款。

## 每条怎么写

一条一行，四个字段：

```
结论：一句话说清是什么事（不超过 40 字）
出处：章节标题或段落位置（用原文里的标题，不要自己编号）
谁做：责任单位或人（没写写"未提及"）
时限：日期或节点（没写写"未提及"）
```

## 不做什么

不写「本文主要讲了……」这类概括。不抄整段原文；要引原句时最多一句，用引号。不编文件里没有的数字、日期、单位；查不到就写「文件中未提及」。不把同一条拆成多条，也不把并列的几件事合成一条。

## 输出后自检

条数少于 5 条先想是不是漏读了后半篇（next_offset 没到 null）。每条都问一遍：这句在原文哪一段？答不出就删。
