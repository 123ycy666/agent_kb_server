# 文章纠错

## 查什么（按顺序，前两类先杀）

1. **错字与别字**：形近字（已/己/巳）、同音字（的/地/得、做/作）、多字漏字。
2. **标点与格式**：中英文标点混用、顿号与逗号错用、"（一）"后又加顿号、书名号书名不对。
3. **数字与口径**：金额单位不统一（元/万元混着写）、百分比与小数混用、合计不等于分项之和、同一指标前后两个数。
4. **名称与称谓**：单位全称不规范（"国网随县供电公司"写成"随县公司"）、人名职务错位、首次出现没写全称。
5. **逻辑与前后矛盾**：前文说"已完成 5 项"后文说"全部完成"、问题与措施不对应、时间顺序倒置。

## 每条怎么写

```
原文：……
改为：……
理由：【错字 / 标点 / 数字 / 名称 / 逻辑】一句话
```

## 不做什么

不把风格偏好当错误（"我觉得这句可以更简洁"→不写）。不改作者的观点与结构。拿不准的另列「待确认」，不混进错误清单。

## 交付形态

清单优先：先给改动条数与前 3 条最要紧的，再给完整清单。要出修订稿时，按《公文格式》或《写工作汇报》的做法重新套版式，正文只做上面列出的改动，不顺手改别的。
