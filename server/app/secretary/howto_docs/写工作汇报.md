# 写工作汇报

## 什么时候用

要一份能直接交上去的成文材料：预算执行情况、专项工作进展、年度总结、问题整改汇报。

## 结构（缺一不可）

一、总体情况：给结论和关键数字，两三句。领导只看这一段也能明白。
二、主要工作与成效：2–4 条，每条先写动作再写结果数字。
三、存在问题：写真的问题，带数（哪个所、差多少、超几天）。没有问题就写"暂无"。
四、下一步措施：一条对一个问题，写清做什么、谁做、什么时候完成。

落款：单位全称 + 成文日期。

## 篇幅与口吻

1200–2500 字，超过 6 页要分节。汇报口吻：陈述句，不设问、不感叹、不夹带建议书式的"我们建议"。数字用阿拉伯数字，金额写到元或万元并统一单位。

## 怎么做

1. 先定要几段（上面四段），每段要哪些数，缺的数先查，查不到就在报告里写"需另行核实"，不许留空。
2. 数字先落表（口径、单位、期间、范围），再写文字；文字只解释表里的数，不重新算。
3. 写完按 check 逐项对，再交 `inspect_docx` 判「结论: 通过」。

## 常见错法（实测栽过）

- 结论段写"预算分配总额需另查"，后面又列出四家金额 —— 自相矛盾。
- 把明细逐行念一遍，没有归纳。
- 存在问题写得笼统（"仍有差距"），没有点名到所、到数。
- 下一步措施与问题不对应，各说各的。
