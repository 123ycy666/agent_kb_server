# 出 Excel 台账

## 结构

1. 第一行大标题（合并整行）：`2025年××统计表`。
2. 第二行表头：字段名，带单位，如 `投入金额(元)`；两级表头时上级合并。
3. 数据区：一行一条，不合并单元格，不留空行。
4. 合计行：最后一行，首列写"合计"，加粗，数字列求和（用公式或算好的值）。

## 数字格式

- 金额：`#,##0.00`（元）或 `#,##0.00_ `（万元）；不写"万"字在单元格里。
- 比例：`0.00%`，值存小数（0.4381 显示 43.81%）。
- 计数：`0` 或 `#,##0`。
- 名次：`0`，不加千分位。

## 列与会话

列宽自动估算不够时按内容给：编号 6、单位名 13、所名 14、金额 14、比例 10。

冻结表头（数据从第 2 行起 → `A3`；只有一行表头 → `A2`）。sheet 名不超过 31 字，写清内容与期间，如 `2025年预算考核`。

## 怎么做

1. 先确认口径：期间（年/月）、范围（全市/某所）、单位（元/万元）。
2. 从库里取数，取数 SQL 里就算好合计与占比，不要导出后手工加。
3. 用 `make_file(kind=xlsx)` 出文件，spec 里给 header / rows / formats / widths / total_row / freeze。
4. 出完跑 `inspect_workbook`，判「结论: 通过」；再自己看一遍列宽和格式有没有 #### 。

## 常见错法（实测栽过）

- 数字以文本形式存进单元格（左上角绿三角），合计算不出来。
- 百分比直接存 43.81 又标 `0.00%` → 显示 4381%。
- 直接导出明细不合计，领导还得自己加。
- 表头没单位，读的人不知道是元还是万元。
